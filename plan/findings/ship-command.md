# Находки прогонов команды `/ship`, 2026-08-09

Источник: первый прогон `/ship` после её появления (волна S16), главная сессия. Формат и правила —
`plan/ORIENT.md` §5.

## ship-command-1 · Шаг 1 `/ship` ищет pickaxe'ом и называет коммит появления версии, а не последнего её движения
Найдено: главная сессия, первый прогон `/ship` после S16
Класс: ИЗМЕРЕНО. Шаг 1 команды предписывает
`git log -S '"version"' --oneline -- plugins/<name>/.claude-plugin/plugin.json`. `-S` — pickaxe: он
матчит коммиты, где изменилось **число вхождений** строки, а подъём `1.1.0 → 1.2.0` число вхождений
`"version"` не меняет. Замер на обоих плагинах:

- `adw` — `-S` → `b67982d` («the plugin gets a version, and it starts at 1.0.0»); `-G` → `ec6a11b`
  (`1.1.0 → 1.2.0`), и между ними ещё `eb0c5c0` (`1.0.0 → 1.1.0`), которого `-S` тоже не видит;
- `run-report` — `-S` → `1276c3c` (переименование: файл возник по этому пути); `-G` → `2ec59af`
  (`1.1.2 → 2.0.0`).

Что сломается: шаг 2 собирает шипящийся дифф от названного sha, и по неверному он собирает уже
поставленное. Замер контрфактуала: `git log --oneline b67982d..HEAD -- plugins/adw/` → **21 коммит**,
среди них `feat(agents)` и `feat(skills)` минорного класса, отгруженные в `1.1.0` и `1.2.0`. Верный
ответ этого прогона — «шипить нечего»; по неверному sha команда предложила бы `1.2.0 → 1.3.0` за
работу, за которую версия уже двигалась дважды. Провал тихий: команда отрабатывает без ошибки и
выводит правдоподобный sha, а расхождение видно только тому, кто помнит историю версий. Класс тот же,
что F-71 и F-132 — записанная команда, дающая правдоподобный вывод не о том предмете.

Решение отложено до: человек. Развилки: (а) заменить в шаге 1 `-S` на `-G` — одна буква, лечит
экземпляр; (б) то же плюс `--follow`, потому что у `run-report` файл пережил переименование каталога и
без `--follow` история обрывается на `1276c3c` (обе формы замерены в этом прогоне); (в) шаг 1 вообще
перестаёт искать коммит и сверяет `version` из `plugin.json` с последним тегом/CHANGELOG — крупнее и
у `adw` не на что опереться, changelog'а у него нет по решению.
