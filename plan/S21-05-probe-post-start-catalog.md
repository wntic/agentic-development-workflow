# S21-05 — замер: доступен ли сабагентам каталог скиллов, появившийся после старта сессии

Тип агента: **`adw-prober`**
Слой: **дев-запись** (`plan/PLATFORM.md`)
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — седьмая чистка (волна S21), прогоны цикла», строка **F-272**; открытый пункт
`plan/PLATFORM.md` про каталог `skills/`, созданный после старта сессии (НЕ ПРОВЕРЕНО, след F-60).

**Что это за задача.** В замеренном прогоне имплементатор уложил 64 файла greenfield с нулём вызовов
`Skill`, при том что днём раньше та же роль на изменении вдесятеро меньшем вызвала десять. Ключевое
отличие сессии: плагин был установлен **внутрь** сессии, а не до её старта. Что происходит со
скиллами каталога, появившегося после старта, `PLATFORM.md` помечает НЕ ПРОВЕРЕНО и уже называет
эксперимент: живая сессия на FIFO по образцу вопроса 5, где новый каталог скилла создаётся между
ходами. Задача — провести этот эксперимент и записать только наблюдённое.

Читать сначала:

- `plan/PLATFORM.md` — вопрос 5 (методика живой сессии на FIFO) и раздел про F-60 (строки ~724–…,
  включая абзац с НЕ ПРОВЕРЕНО на ~937 и честную границу про `SIDECHAIN tool_use: {}`);
- тело записи грепом: `rtk proxy grep -n '^## F-272 ' plan/findings/legacy.md`, затем ~23 строки;
- строку решения по F-272 в секции решений 2026-08-10 (седьмая чистка) в конце того же файла.

## Задача

1. Собрать выбрасываемый стенд в scratchpad (по образцу `probe9/toolplug`): плагин/каталог с одним
   скиллом вымышленного формата, чей факт загрузки отличим от галлюцинации (уникальная константа в
   теле).
2. Живая сессия на FIFO. Ход 1 — каталога ещё нет: диспатч сабагента с вопросом по предмету скилла,
   зафиксировать ответ. Между ходами — создать/установить каталог. Ход 2 — тот же диспатч: виден ли
   скилл сабагенту (авто-инвокация по description; `Skill` в tools). Ход 3, если различимо, —
   после рестарта сессии, как контроль.
3. Записать в `plan/PLATFORM.md` датированный раздел по форме файла: команда, вывод, вывод из
   вывода; НЕ ПРОВЕРЕНО — законченный ответ там, где установить не удалось. Снять или уточнить
   существующую пометку НЕ ПРОВЕРЕНО, **не переписывая** датированные разделы прошлых замеров.
4. Версию платформы (`claude --version`) — в раздел.

## Deliverables

Датированный раздел в `plan/PLATFORM.md`; стенд в scratchpad (в дерево не попадает). Больше ничего.

## Границы

  не трогать.

- Не чинить найденное по дороге: находка — в отчёт.
