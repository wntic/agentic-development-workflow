# S10-17 — четыре находки уезжают в репозиторий инструмента

Тип агента: **`adw-builder`**
Слой: **вне репозитория** (`~/Projects/claude-agent-report`)
Происхождение: решение человека 2026-08-05, `plan/FINDINGS.md`, секция «Решения человека, 2026-08-05 —
раунд 2: указатели, карта и чужой инструмент», строки **F-150**, **F-153**, **F-157**, **F-194**.

**Что это за задача и чего она не делает.** Четыре записи про `claude-agent-report` закрыты решением
«уезжают в свой репозиторий»: инструмент не наш, не под `plugins/adw/`, и правится в своём доме. Довод
решения назван прямо: мы четырежды отложили правку инструмента, которым судим прогоны, и ни разу его не
тронули — то есть носили чужой бэклог в реестре воркфлоу. Задача **переносит записи**, а не чинит
инструмент: код `claude-agent-report` в этой задаче не правится.

Читать сначала:
- в `plan/FINDINGS.md` — тела **F-150**, **F-153**, **F-157**, **F-194** заголовочным грепом
  (`rtk proxy grep '^## F-' plan/FINDINGS.md`, потом читать только эти четыре записи), и четыре строки
  диспозиции в названной секции;
- там же — тела **F-117**, **F-118**, **F-142**, **F-111**: F-150 и F-153 на них ссылаются, и без них issue
  будет непонятен читателю чужого репозитория;
- `~/Projects/claude-agent-report/README.md` — чтобы issue говорил на языке этого проекта, а не нашего;
- `git -C ~/Projects/claude-agent-report log --oneline -5` и `git -C ~/Projects/claude-agent-report status -sb`
  — состояние дерева и remote: по F-159 у плагина из `github` дерево и установка связаны через remote, и
  issue заводится там, где живёт remote.

## Задача

**1. Установить, куда именно заводить.** Проверь, есть ли у репозитория remote на GitHub и включены ли
issues (`gh repo view --json hasIssuesEnabled,url` или равное). Если issues выключены или `gh` не
авторизован — **остановись и доложи**: заводить некуда, и придумывать замену не надо.

**2. Четыре issue, по одному на запись.** Каждый несёт:

- **что наблюдалось**, с командой и выводом — они уже есть в телах записей, бери оттуда дословно;
- **на какой версии инструмента** — из `installed_plugins.json` или из дерева;
- **чего не надо делать**: наш номер записи (`F-153`) в тексте issue не нужен — он ничего не значит для
  читателя того проекта. Ссылку на нашу запись класть **не надо**: реестр не публичен.

Предметы четырёх:

| запись | предмет |
|---|---|
| F-150 | дробление по `;` и `&&` не покрывает сцепление **переводом строки**, и флагманский пример остаётся с двумя вердиктами в ячейке |
| F-153 | `VERDICT_PATTERN` не знает формы провала `ruff format --check` (`N file(s) would be reformatted`), и до дробления это давало **зелёную строку на упавшей команде** |
| F-157 | звено после упавшего `&&` не исполняется, но получает свою строку и идёт в счёт запусков; красный от `is_error` ложится на команду, которая не запускалась |
| F-194 | ростер считает убитые API-ошибкой диспатчи (`<synthetic>`, тип `?`) наравне с настоящими, и колонка `active` подписана «compute time», хотя включает сегменты, где агент ждал |

**3. В нашем реестре — по строке на запись** о том, куда уехало: номер issue и его URL. Это **не** новая
диспозиция, а исполнение уже принятой; пиши в конец `plan/FINDINGS.md` одной секцией.

## Deliverables

Четыре issue в `~/Projects/claude-agent-report` (или доклад «заводить некуда» с причиной), и одна секция в
`plan/FINDINGS.md` с их номерами. Больше ничего.

## Границы

- **Код `claude-agent-report` не править.** Ни строки. Решение человека — «уезжают в свой репозиторий», а
  не «чинятся сейчас».
- **`plugins/adw/` не трогать вовсе.**
- **Полстроки в `ORIENT` §5** про то, чему у отчёта не верить, принадлежит задаче **S10-02** — не пиши её
  здесь.
- **Номера наших записей в тексты issue не вносить** — они ничего не значат вне этого репозитория.
- **Ничего не пушить и не открывать PR** в чужом репозитории: задача заводит issue, и только.
- Не чинить найденное по дороге — находка идёт в `plan/FINDINGS.md`, и пишет её главная сессия.

```bash

# до: пусто. После: пусто — код инструмента не тронут

# до: (может быть непусто — параллельные задачи волны). После: столько же файлов, сколько было:
# эта задача в plugins/adw/ не пишет
rtk proxy grep -c 'claude-agent-report' plan/FINDINGS.md
# до: 6. После: больше 6 — секция про уезд написана
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- **код чужого репозитория не тронут** — `git status --porcelain` там пуст, и это главный пункт: решение
  было «уехать», а не «починить»;
- **`plugins/adw/` не изменён этой задачей**;
- **в issue нет наших номеров записей** — они бессмысленны вне реестра, а реестр не публичен;
- **каждый issue несёт команду и вывод**, а не пересказ: это то, чем находка отличается от жалобы;
- **в реестре есть строка на каждую запись** с номером issue, иначе «уехало» неотличимо от «забыто».
