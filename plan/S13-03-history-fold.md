# S13-03 — `HISTORY.md` сжимается в `CLAUDE.md`; указатели `WORKFLOW.md` и `CLAUDE.md` на реестр

Тип агента: **`adw-builder`**
Слой: **дев-запись + канон (перестановка указателей, не смена решений)**
Происхождение: решение человека 2026-08-09, `plan/FINDINGS.md`, секция «Решения человека, 2026-08-09 —
реестр по источникам, снос HISTORY.md», буллеты «`HISTORY.md` сносится, функция сжимается в
`CLAUDE.md`» и «Миграция» (в части указателей на реестр).

**Что это за задача и чего она не делает.** `HISTORY.md` — 86 строк: таблица трёх попыток, цифры
провала третьей, «что где лежит» под тегами и правило «не перестраивай удалённое по памяти». Человек
решил: файл удаляется, несущая функция — прайс-лист против отращивания — сжимается в `CLAUDE.md`.
Заодно `CLAUDE.md` и `WORKFLOW.md` перестают указывать на `plan/FINDINGS.md` как на живой файл.
Задача **не** переписывает канон по существу: каждое изменение в `WORKFLOW.md` — замена адреса или
снятие ссылки на удалённый файл, и ничего больше.

Читать сначала:

- секция решений, названная выше;
- `HISTORY.md` целиком — что именно сжимается и что теряется осознанно (перечень «что где» по тегам
  сжимается до указания тегов; длинный список путей не переезжает);
- `rtk proxy grep -n 'HISTORY' CLAUDE.md WORKFLOW.md` и `rtk proxy grep -n 'FINDINGS' CLAUDE.md
  WORKFLOW.md` — все места, которые правишь.

## Задача

**1. Блок истории в `CLAUDE.md`.** В раздел «What this repository is», на место нынешней ссылки на
`HISTORY.md`, — компактный английский блок (≤12 строк): три предыдущие попытки живут под git-тегами
(`v2-archive` — YAML-манифест+валидатор, первая попытка в его истории; `v3-archive` — спеки + 17 200
строк enforcement, 64 задачи, 0 фич); правило — **не перестраивай удалённый механизм по памяти:
достань файл из тега (`git show v3-archive:<путь>`) и прочти, что он стоил**; самые дорогие уроки уже
дистиллированы в `WORKFLOW.md` §8. Прочие упоминания `HISTORY.md` в `CLAUDE.md` — снять или заменить
указанием на этот блок.

**2. Снос `HISTORY.md`.**

**3. `WORKFLOW.md` — только указатели**: шапка документа ссылается на `HISTORY.md` — заменить на
«теги `v2-archive`/`v3-archive», указатель — блок истории в `CLAUDE.md`»; всякое упоминание
`plan/FINDINGS.md` как живого адреса (греп покажет) — на `plan/findings/` (файл источника). Ничего
содержательного не менять; если замена адреса меняет смысл предложения — **стоп и доклад**, это
вопрос человеку.

**4. `CLAUDE.md` — адреса реестра**: строки «open questions are `plan/FINDINGS.md`, read by header
(`rtk proxy grep '^## F-'`) and never whole», «defect logs … under the step-2/step-3 headings» и
родственные — привести к новой модели: открытое — `ls plan/findings/`, формат — `ORIENT` §5,
замороженная серия и история — git. Дефект-логи прошлых шагов остаются историческим фактом — их
упоминания получают оговорку «в git-истории реестра», не удаление.

## Deliverables

Правленые `CLAUDE.md` и `WORKFLOW.md`, удалённый `HISTORY.md`. Больше ничего.

## Границы

- В `WORKFLOW.md` не меняется ни одно решение, ни один механизм, ни одна красная линия — только
  адреса и снятие ссылок на удалённый файл. Сомнение — стоп и доклад.
- `plan/*` не трогать вовсе; `.claude/*` не трогать.
- Блок истории — сжатие, не пересказ: цифры (64, ~17 200, 0) и теги переезжают точно, длинные
  таблицы «что где лежит» — нет. Для подробностей блок даёт команду восстановления самого файла из
  истории — `git log --oneline -- HISTORY.md` затем `git show <sha>:HISTORY.md` — и не выдумывает
  других форм: под тегами `v2-archive`/`v3-archive` этого файла нет, он жил только в рабочем дереве
  четвёртого захода.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
test -f HISTORY.md && echo ALIVE || echo GONE
# до: ALIVE. После: GONE
rtk proxy grep -c 'HISTORY\.md' CLAUDE.md WORKFLOW.md
# до: CLAUDE.md:3, WORKFLOW.md:2 (пересчитай при исполнении). После: 0 живых указателей —
# допустимо упоминание в форме «достань из git-истории», и только оно
rtk proxy grep -c 'v3-archive' CLAUDE.md
# до: 2. После: ≥2 — теги переехали в блок истории
rtk proxy grep -n 'plan/FINDINGS\.md' CLAUDE.md WORKFLOW.md
# до: непусто. После: ноль живых адресов записи; оставшееся — только про git-историю
git status --porcelain -- plan/ .claude/ plugins/
# до и после: без изменений от этой задачи
```

## Что скажет warden

- `WORKFLOW.md`: дифф — только адреса и ссылки; ни одна строка решений, механизмов и красных линий
  не переформулирована;
- блок истории в `CLAUDE.md` несёт теги, цифры и правило — и не разрастается в пересказ HISTORY;
- живых указателей на два удалённых файла (`HISTORY.md`, `plan/FINDINGS.md`) по этим двум файлам нет;
- `plan/` и `.claude/` этой задачей не тронуты.
