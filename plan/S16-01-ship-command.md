# S16-01 — команда `/ship`: подъём версии по записанному правилу, решает человек

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`.claude/commands/ship.md` — project-scoped, не шипится)
Происхождение: решение человека 2026-08-09, `plan/INDEX.md`, секция «`/ship` и худеющий legacy — S16»,
буллет «Команда `/ship`».

**Что это за задача.** Правило движения версии записано в `plan/INDEX.md` («Версия плагина — правило
движения»: таблица мажор/минор/патч/нет подъёма, подъём при публикации, решение человека), но в момент
«может шипнем?» его никто не открывает — агент двигает версию по ощущению, накопленные минорные
изменения теряются. Задача пишет **один файл** — команду `/ship`, которая готовит решение по таблице
и оставляет сам выбор человеку.

Читать сначала:

- `plan/INDEX.md`, секция «Версия плагина — правило движения» — целиком: таблица, «подъём при
  публикации», замеренная оговорка про `source: directory` (семвер платформа не читает — версия пока
  документация для людей);
- `.claude/commands/debrief.md` и `interview.md` — голос и формат фронтматтера соседей по петле;
- `plugins/adw/.claude-plugin/plugin.json` и `plugins/agent-report/.claude-plugin/plugin.json` — где
  живут версии; у `agent-report` есть свой `CHANGELOG.md`, у `adw` ченджлога нет и не заводится.

## Задача

Один файл `.claude/commands/ship.md`, по-английски (русские идентификаторы дев-записи — как данные).
Фронтматтер: `description` (prepare a version bump for the marketplace plugins by the recorded rule;
the human decides), `argument-hint` (`[adw | agent-report | пусто — оба]`). Тело — шаги главной
сессии:

1. **Найти последнее движение версии** каждого плагина: `git log -S '"version"' --oneline --
   plugins/<name>/.claude-plugin/plugin.json` — первый коммит списка; версий два, у каждого плагина
   свой отсчёт.
2. **Собрать шипящийся дифф** от того коммита: `git log --oneline <sha>..HEAD -- plugins/<name>/`.
   Пусто — сказать «нечего шипить» и остановиться.
3. **Классифицировать построчно по таблице** «Версия плагина — правило движения» из `plan/INDEX.md`
   — таблица читается при прогоне, копии в команде нет (класс F-132: стоячая копия расходится
   молча). Версия двигается по **сильнейшему** классу накопленного диффа; правки только дев-записи
   в счёт не идут.
4. **Предложить человеку**: текущая версия → предлагаемая, обоснование по строкам диффа с классом
   каждой. `AskUserQuestion` — можно; человек может переопределить любой класс и итог. Без его
   решения ничего не двигается.
5. **По решению**: правка `version` в `plugin.json` (у `agent-report` — плюс секция в его
   `CHANGELOG.md`, раз он его ведёт), коммит по-английски; **пуш — только по слову человека**,
   отдельным подтверждением (публикация — внешнее действие).

Границы в тексте команды: критерии не изобретаются — только таблица; решение всегда человека;
версия не двигается «за компанию» с волной — только этой командой при публикации.

## Deliverables

Один файл `.claude/commands/ship.md`. Больше ничего.

## Границы

- `plan/INDEX.md` не трогать — строку о `/ship` в правило версии вносит главная сессия.
- `plugins/**` не трогать: команда пишется, не исполняется.
- Таблицу правила в команду не копировать — цитируется дом.
- Не чинить найденное по дороге: находка — в отчёт.
