# S17-01 — урок F-284 в правило переноса плагина

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`plugins/README.md` лежит под `plugins/`, но не под `plugins/adw/` — не шипится)
Происхождение: решение человека 2026-08-09, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-09 — третья чистка (волна S17), партия переноса плагина», строка **F-284**.

**Что это за задача.** При переносе `agent-report` в это дерево pre-commit хозяйского дерева
переформатировал перенесённый скрипт в момент коммита (`ruff format` → 42+/27−, коммит прерван), и
проверка задачи, написанная как «байт-в-байт против исходника», устарела в ту же минуту. Урок
получает дом там, где уже живёт правило переноса, — и получает его **одним-двумя предложениями
прозы**. Механизма в этой задаче нет и быть не должно: решение человека прямо назвало это демоцией
правила в совет по красной линии 2.

Читать сначала:

- `plugins/README.md` целиком — файл короткий; адресат правки — абзац, начинающийся «A plugin that
  arrives from a repository of its own sheds that repository's shell on the way in»;
- `plan/findings/legacy.md`, тело записи `## F-284` — грепом по заголовку, **не читая файл целиком**
  (`ORIENT.md` §5): `rtk proxy grep -n '^## F-284' plan/findings/legacy.md`, затем читать от этой
  строки ~10 строк;
- ту же строку решения в секции «Решения человека, 2026-08-09 — третья чистка (волна S17)» в конце
  того же файла.

## Задача

1. В абзац про сбрасывание оболочки чужого репозитория (`plugins/README.md`) добавить одно-два
   предложения: тулчейн этого дерева трогает пришедший код на входе — pre-commit переформатирует его в
   момент коммита, — поэтому проверка «приехало без изменений» пишется **против закоммиченного
   состояния**, а не против рабочего дерева; «не тронут ни строкой» и «прошёл коммит» совместимы
   только у файлов, уже отвечающих тулчейну дерева.
2. Больше ничего. Существующие предложения абзаца не переписываются; перечень того, что плагин
   сбрасывает (`marketplace.json`, `LICENSE`, `.gitignore`) и что оставляет — не трогать.

Файл шипится наружу как проза репозитория и по решению 2026-08-09 остаётся английским — новые
предложения пишутся по-английски, в тоне соседних.

## Deliverables

Правка в одном файле `plugins/README.md`. Больше ничего.

## Границы

- Ни `plugins/adw/**`, ни `plugins/run-report/**`, ни `CLAUDE.md`, ни `plan/**` не трогать.
- Никакого механизма: ни хука, ни скрипта, ни строки в `.pre-commit-config.yaml`. Урок — проза.
- Не пересказывать тело F-284 и не ссылаться на номер находки в `README.md`: файл читают снаружи, а
  реестр находок — дев-запись.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -c 'sheds that repository' plugins/README.md
# до: 1. После: 1 — абзац на месте и не переписан заново
rtk proxy grep -c 'committed state' plugins/README.md
# до: 0. После: ≥1 — проверка равенства адресована закоммиченному состоянию
rtk proxy grep -c 'pre-commit\|toolchain' plugins/README.md
# до: 0. После: ≥1 — названа причина, а не только предписание
rtk proxy grep -c 'LICENSE' plugins/README.md
# до: 2. После: 2 — перечень сбрасываемого не тронут
git diff --stat -- plugins/README.md
# до: пусто. После: один файл — вклад задачи только здесь
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `plugins/README.md`, и в нём только добавленная проза: ни одно существующее
  предложение не сменило смысл;
- добавленное — совет, а не устройство: в диффе нет ни скрипта, ни хука, ни конфигурации проверки;
- текст английский и в тоне файла; номера находки и слов дев-записи в нём нет;
- перечень того, что плагин сбрасывает и что оставляет, не тронут.
