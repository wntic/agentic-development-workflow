# S12-01 — перенос `agent-report` в этот маркетплейс вторым плагином

Тип агента: **`adw-builder`**
Слой: **маркетплейс (не adw)** — `plugins/agent-report/`, `.claude-plugin/marketplace.json`, одна
правка `CLAUDE.md`
Происхождение: решение человека 2026-08-09, `plan/FINDINGS.md`, «Дополнение решения 2, 2026-08-09 —
`agent-report` становится вторым плагином этого маркетплейса, и правило счёта».

**Что это за задача и чего она не делает.** Инструмент отчёта живёт отдельным репозиторием
(`~/Projects/claude-agent-report`, версия 1.1.2, дерево чистое, `main == origin/main`, `c1d2dee`) и
отдельным маркетплейсом; человек хочет одну сущность вместо двух. Задача **переносит** плагин в
`plugins/agent-report/` и регистрирует его в манифесте маркетплейса. Она не чинит его: у инструмента
четыре открытые записи в реестре (F-150, F-153, F-157, F-194), и все ждут интервью — ни строки
`scripts/agent_report.py` эта задача не меняет. Красные линии правят воркфлоу `adw`; этот плагин —
платформенный инструмент наблюдаемости со своим жизненным циклом, его скрипт в бюджет enforcement
воркфлоу не входит, и проверка красной линии 2 (`find plugins/adw …`) остаётся верной дословно.

Читать сначала:

- «Дополнение решения 2» в `plan/FINDINGS.md` — рамки решения, включая снятую S10-17;
- `~/Projects/claude-agent-report/.claude-plugin/plugin.json` — что переносится;
- `.claude-plugin/marketplace.json` этого репозитория — куда добавляется запись;
- первый раздел `CLAUDE.md` («What this repository is») — предложение, которое станет неверным после
  переноса («holding one plugin»);
- тела F-263 и F-265 в `plan/FINDINGS.md` (заголовочным грепом, потом только эти два): `claude plugin
  validate` шумит на adw по известной причине, а установка из каталога читает рабочее дерево — обе
  вещи влияют на то, что твоя проверка может и чего не может показать.

## Задача

**1. Перенос дерева.** Всё содержимое `~/Projects/claude-agent-report`, кроме `.git/`, копируется в
`plugins/agent-report/` байт-в-байт: `.claude-plugin/`, `commands/`, `scripts/`, `README.md`,
`CHANGELOG.md`, `LICENSE`, `.gitignore`.

**2. Два поля манифеста плагина.** В скопированном `plugin.json` поля `homepage` и `repository`
меняются на `https://github.com/wntic/agentic-development-workflow` — прежние указывают на
репозиторий, который человек архивирует после миграции. Версия `1.1.2` и всё остальное — без правок.

**3. Запись в маркетплейсе.** В `.claude-plugin/marketplace.json`, в массив `plugins`, вторым
элементом: `{"name": "agent-report", "source": "./plugins/agent-report"}`.

**4. `CLAUDE.md`, первый абзац.** «A Claude Code marketplace holding one plugin, `plugins/adw/`…» —
привести к факту: маркетплейс несёт два плагина — `plugins/adw/` (воркфлоу; весь остальной документ о
нём, красные линии правят его) и `plugins/agent-report/` (инструмент наблюдаемости: транскрипты
сессий → Markdown-отчёт; **сознательно вне воркфлоу и его красных линий** — его скрипт легален и в
бюджет enforcement не входит, проверка бюджета скоупится `plugins/adw`). Минимальный дифф: правится
одно место, новых разделов нет.

## Deliverables

`plugins/agent-report/` (перенесённое дерево с двумя правлеными полями манифеста), одна запись в
`.claude-plugin/marketplace.json`, правка одного места в `CLAUDE.md`. Больше ничего.

## Границы

- **`scripts/agent_report.py` не править ни строкой** — F-150/F-153/F-157/F-194 ждут интервью, не
  переноса.
- **`plugins/adw/` не трогать вовсе.**
- Исходный репозиторий `~/Projects/claude-agent-report` — только чтение; не архивировать, не пушить,
  не менять.
- Установку/удаление плагинов не выполнять — миграция установки за главной сессией.
- Не чинить найденное по дороге: находка идёт в отчёт, пишет её главная сессия.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
diff -rq --exclude=.git ~/Projects/claude-agent-report plugins/agent-report
# до: diff: plugins/agent-report: No such file or directory. После: одна строка — differ только
# .claude-plugin/plugin.json (два правленых поля); других расхождений нет
rtk proxy grep -c '"source"' .claude-plugin/marketplace.json
# до: 1. После: 2 — вторая запись в манифесте
python3 plugins/agent-report/scripts/agent_report.py --cwd "$PWD" --session latest >/dev/null && echo RUNS
# до: файла нет, python3 падает. После: RUNS — скрипт исполняется из нового дома
git status --porcelain -- plugins/adw/
# до: пусто. После: пусто — adw не тронут
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2, её скоуп — plugins/adw, и он не изменился
```

## Что скажет warden

- перенос байт-в-байт: `diff -rq` показывает ровно одно отличие — два поля `plugin.json`; любая
  правка скрипта — прямое нарушение решения («переносит, не чинит»);
- `plugins/adw/` не изменён ни байтом, проверка красной линии 2 зелёная и её формулировка не тронута;
- запись маркетплейса — одна и минимальная; версия плагина осталась `1.1.2` (движется в своём
  жизненном цикле, не нашим проходом);
- `CLAUDE.md` говорит явно: красные линии — про `adw`, второй плагин вне их, скрипт в нём легален;
- четыре открытые записи об инструменте не «починены по дороге».
