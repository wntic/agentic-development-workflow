# S19-02 — определение warden'а перестаёт велеть голый `git status`

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`.claude/agents/` — project-scoped, не шипится; версия не двигается)
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — пятая чистка (волна S19), числа об идущей волне и watch-list», строка **F-276**.

**Что это за задача.** Пункт 3 секции «What you read first» в `.claude/agents/adw-warden.md` велит
роли самой гонять `git status --short` + `git diff` без оговорки о параллельном следе. Протокол
цепочки (`plan/INDEX.md`, шаг 2) обходит это оговоркой в каждом промпте диспатча и называет F-276
открытой. Соседний замер — F-99: `git status` у builder'ов в параллельной волне дал ложный красный
на честной работе. Текст роли приводится к протоколу: вердикт судит работу задачи, а список её
файлов приходит от диспетчера.

Читать сначала:

- `.claude/agents/adw-warden.md` — секция «What you read first» целиком, пункт 3 — адресат;
- `plan/INDEX.md`, «Протокол цепочки», шаг 2 — форма, к которой приводится роль (список изменённых
  файлов от главной сессии в промпте; оговорка про чужие следы);
- тело записи грепом по заголовку, **не читая `legacy.md` целиком** (`ORIENT.md` §5):
  `rtk proxy grep -n '^## F-276 ' plan/findings/legacy.md`, затем ~12 строк;
- строку решения по F-276 в секции решений 2026-08-10 в конце того же файла.

## Задача

1. Пункт 3 переписать: изменённые файлы называет промпт диспатча — читай их диффы по этим путям
   (`git diff -- <paths>`, включая staged); не верь отчёту на слово — читай сами файлы. Голый
   `git status --short` из пункта уходит; вместо него — оговорка: следы других задач в дереве при
   параллельной волне — не предмет твоего вердикта (F-276; соседний замер у builder'ов — F-99).
2. Полстроки-строка сверх замены команды; остальной файл не трогать.

Файл — агент, по решению 2026-08-09 он строго английский; новые строки — по-английски, в тоне файла.

## Deliverables

Правка в одном файле `.claude/agents/adw-warden.md`. Больше ничего.

## Границы

- `plan/**` (кроме чтения), `plugins/**`, `.claude/commands/**`, другие агенты — не трогать.
- Read-only-природа роли, список запретов, секция про ruling'и — не трогаются.
- Никакого механизма: меняется инструкция чтения, не появляется проверка.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -c 'git status --short' .claude/agents/adw-warden.md
# до: 1. После: 0 — голая команда из определения ушла
rtk proxy grep -c 'F-276' .claude/agents/adw-warden.md
# до: 0. После: ≥1 — оговорка несёт свой замер
rtk proxy grep -c 'git diff' .claude/agents/adw-warden.md
# до: 2. После: ≥1 — чтение диффа осталось, по путям из промпта
git diff --stat -- .claude/agents/adw-warden.md
# до: пусто. После: один файл — вклад задачи только здесь
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `.claude/agents/adw-warden.md`, тронут только пункт 3 секции чтения;
- роль осталась read-only и по-прежнему читает сами файлы, а не отчёты;
- оговорка о чужих следах цитирует F-276/F-99, а не пересказывает их тела;
- текст английский; механизма нет.
