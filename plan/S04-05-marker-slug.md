## Задача

Пространство маркеров `ac` общее на всё дерево. `pytest -m ac` выбирает и маркеры уже **принятых**
изменений: на прогоне 002 из 18 выбранных тестов **11 принадлежали 001**, и вопрос «покрыт ли AC-5 у
002?» по маркеру дал **ложное «да»**. Воспроизвелось трижды.

Правило, вернувшееся в `test-principles`, учит с этим жить — искать свой `AC-n`, а не считать
выбранные тесты. Решение идёт дальше: **смысловой идентификатор убирает коллизию по построению**.
Порядковый номер уникален только внутри своего изменения; фраза, описывающая поведение, уникальна
сама по себе.

Побочная выгода, названная в решении: читатель теста понимает, **что** критерий утверждал, не
поднимая номер изменения из тега. Durable-связь при этом не меняется — она по-прежнему идёт от
инварианта живой спеки к имени теста, — поэтому **F-37 не переоткрывается**.

## Deliverables

Три файла.

### 1. `plugins/adw/templates/criteria.md`

- Пункт чеклиста несёт **и** порядковый номер (он нужен человеку, чтобы ссылаться в разговоре и в
  `verdict.md`), **и** слаг. Форма — из `WORKFLOW.md` §3 после S04-02, дословно.
- Правила для слага, коротко: строчные, через дефис, описывает **наблюдаемое поведение**, а не
  реализацию; уникален внутри изменения; не несёт номера изменения (это `process state`, F-37).
- Список слов-маркеров расплывчатости (`correctly`, `properly`, `works`, `as expected`) **не
  трогать** — он закрыт решением по F-13.

### 2. `plugins/adw/commands/spec.md`

- Интервью производит слаг вместе с текстом критерия — там, где пишется `criteria.md`.
- В выходной контроль (раздел 6) — один пункт: у каждого критерия есть слаг, он описывает поведение,
  и он уникален внутри изменения. **Пунктов ровно на один больше**, не на три.

### 3. `plugins/adw/skills/test-principles/SKILL.md`

- Правило маркера переписывается под смысловой id. Что сохранить дословно по смыслу: один маркер на
  критерий; маркер — запись доказательства, а не категория; регистрация в
  `[tool.pytest.ini_options] markers`.
- Правило про сквозную выборку `pytest -m ac` перестаёт быть **предупреждением о коллизии** и
  становится описанием: выборка идёт по всей сюите, и это нормально, потому что идентификатор
  однозначен сам по себе.
- **Скилл по-прежнему не называет ни `criteria.md`, ни состояний бокса `[ ]`/`[x]`.** Это F-50,
  закрытая ровно так; вернуть цикловую механику в скилл — значит открыть её заново.

## Границы

- **Только эти три файла.** Ни `WORKFLOW.md` (форму фиксирует S04-02), ни `verdict.md`, ни агенты,
  ни `build.md`.
- **Не переписывать тесты в `adw-probe`** и вообще ничего за пределами этого репозитория. Маркеры,
  уехавшие на `main` пробы, остаются как есть — вычистка чужого дерева по дороге запрещена.
- **Не заводить реестр слагов**, ни файла, ни индекса, ни проверки уникальности машиной. Уникальность
  — свойство формулировки, за неё отвечает автор критерия и читающий человек.
- Не трогать `[m]`/`[x]`/`[ ]` и их значения.
- Не чинить найденное по дороге.
