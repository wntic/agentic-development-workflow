# S15-02 — исторические оговорки в `ORIENT.md`

Тип агента: **`adw-builder`**
Слой: **дев-запись**
Происхождение: решение человека 2026-08-09, `plan/INDEX.md`, секция «Вторая чистка — S15» («`ORIENT.md`
получает исторические оговорки на ссылки удалённых задач»).

**Что это за задача.** После S14 файлы задач волн удалены, а `ORIENT.md` §4 продолжает говорить о них
в настоящем времени. Задача — точечные оговорки историчности в **одном файле**; ни одно правило не
переписывается.

Читать сначала:

- `plan/ORIENT.md` §4 — строка таблицы про команду в секцию «Проверка» («Жива в исполненных файлах
  задач (`S04-02`, `S04-03`, `S04-07`)») и блок про `agent-report` в §5;
- `rtk proxy grep -n 'S04-\|S10-\|исполненных файлах' plan/ORIENT.md` — не осталось ли ещё ссылок на
  удалённые файлы задач (счётная строка §4 уже помечена исторической в S14 — её не трогать).

## Задача

1. §4, строка «Жива в исполненных файлах задач (`S04-02`, `S04-03`, `S04-07`): править там значило бы
   подделать протокол» — привести к факту: экземпляры жили в исполненных файлах задач, которые с S14
   удалены по модели дельт и читаются из git-истории; принцип «исполненное не правится задним числом»
   не трогать.
2. §5, «Если нужен разбор прогона, есть скилл `agent-report`» — привести к живому маршруту: разбор
   прогона запускается командой `/debrief` (она генерирует отчёт и диспатчит `adw-analyst`); сам
   плагин `agent-report` — часть этого маркетплейса.
3. Всё прочее, что найдёт греп из «Читать сначала», — той же оговоркой историчности; ничего не
   удалять и не переписывать шире адресации.

## Deliverables

Правки в одном файле `plan/ORIENT.md`. Больше ничего.

## Границы

- Ни одно правило §4/§5/§6 не переформулируется — меняются только утверждения о существовании файлов
  и маршрут разбора.
- Счётную строку §4, уже помеченную исторической (S14), не трогать.
- `plan/INDEX.md`, `CLAUDE.md`, `.claude/**`, `plugins/**` — не трогать.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -n 'Жива в исполненных' plan/ORIENT.md
# до: одна строка (§4, таблица). После: пусто — формулировка historическая, принцип на месте
rtk proxy grep -c 'подделать протокол\|подделал' plan/ORIENT.md
# до: 1. После: ≥1 — принцип «исполненное не правится» не удалён
rtk proxy grep -c '/debrief' plan/ORIENT.md
# до: 0. После: ≥1 — маршрут разбора живой
git diff --stat -- plan/ORIENT.md
# до: пусто либо след этой задачи. После: один файл — вклад задачи только здесь
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл, и в нём только историчность и маршрут: ни одно правило не сменило смысл;
- принцип «исполненные файлы задач не правятся задним числом» жив дословно или эквивалентно;
- `/debrief` назван как вход разбора, `agent-report` — как часть маркетплейса, без пересказа их тел.
