# S25-06 — двенадцать указателей на `legacy.md` приводятся к факту

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`plan/`, `.claude/` — ничего под `plugins/adw/`, версия не двигается)
Происхождение: решение человека 2026-08-11, `plan/findings/legacy.md`, секция решений одиннадцатой
чистки, блок «Третье дополнение по ходу волны S25». Принято **по ходу волны**, при подготовке
закрывающего коммита.

**Что это за задача.** Закрывающий коммит волны S25 удаляет `plan/findings/legacy.md` — последнюю
открытую часть замороженной серии F, дожитую этой волной. Ссылок на этот файл в дереве **четырнадцать**:

| файл | шт. | род |
|---|---|---|
| `plan/ORIENT.md` | 2 | правила формата реестра — живая инструкция |
| `plan/INDEX.md` | 5 | указатель (1) и цитаты в протоколе цепочки (4) |
| `.claude/commands/interview.md` | 3 | шаги и «Границы» команды — живая инструкция |
| `.claude/agents/adw-warden.md` | 2 | где искать диспозиции — живая инструкция |
| `.claude/agents/adw-builder.md` | 1 | то же |
| `plan/PLATFORM.md` | 2 | **внутри датированных разделов замеров** |

Класс уже открыт как `s15-wave-1`: волна S15 снесла `INSTALL-REHEARSAL.md`, и две ссылки пережили
чистку. Здесь недостача видна **до** коммита.

**Двенадцать чинятся, два — нет.** Вхождения в `plan/PLATFORM.md` стоят внутри датированных разделов
и по правилу задним числом не правятся: они верны на свою дату как адрес решения на момент замера.

Читать сначала:

- полный список: `rtk proxy grep -rn 'legacy.md' plan/ CLAUDE.md .claude/` — прочитать **каждое**
  вхождение с окружением, потому что род у них разный и правка у каждого своя;
- `plan/ORIENT.md` §5 целиком — там живут правила формата реестра, и две ссылки именно в них;
- `plan/INDEX.md`, «Указатели» (одна ссылка) и «Протокол цепочки», шаг 4 (четыре цитаты вида
  «(F-231, `findings/legacy.md`)»);
- строку решения — блок «Третье дополнение по ходу волны S25» в конце `plan/findings/legacy.md`;
- как это уже сделано для снесённого `INSTALL-REHEARSAL.md`: `rtk proxy grep -rn 'INSTALL-REHEARSAL' plan/ CLAUDE.md`
  — форма указателя на снесённый файл в этом репозитории уже задана, и новые ей следуют.

## Задача

1. **`plan/ORIENT.md`** — правила §5 перестают называть `legacy.md` как живой файл: серия F
   заморожена на F-284 и **дожита**; её тела и диспозиции читаются из git-истории
   (`git log -S 'F-NNN' --oneline`, затем `git show <sha>:<путь>`). Правило про «волну, исполнившую
   часть записей», теряет свой единственный адресат — его судьба на усмотрение по месту: снять или
   обобщить, но не оставить указывающим в пустоту.
2. **`plan/INDEX.md`** — четыре цитаты в протоколе (`(F-231, findings/legacy.md)` и соседние) теряют
   адрес файла: номер находки остаётся, адрес становится git-историей либо снимается вовсе — правило
   от этого не меняется, оно и так стоит своими словами. Указатель в «Указателях» уже приведён к
   факту главной сессией — **проверить и не задвоить**.
3. **`.claude/commands/interview.md`** — шаг 2 и две строки «Границ» больше не могут называть
   `legacy.md`. Смысл правил сохраняется: тела читаются **точечно** (это верно для любого файла
   находок), и прежние формы диспозиций задним числом не переписываются.
4. **`.claude/agents/adw-warden.md`, `.claude/agents/adw-builder.md`** — оговорка «(or, for the
   frozen F-series, `plan/findings/legacy.md`)» снимается или заменяется на git-историю: роли ищут
   диспозиции в файле события-источника под `plan/findings/`, и другого места больше нет.
5. **`plan/PLATFORM.md` не трогать вовсе** — оба вхождения в датированных разделах.

Файлы `.claude/**` — агенты и команды, по решению 2026-08-09 строго английские; `plan/**` — русские.
Править каждый на его языке.

## Deliverables

Правки в пяти файлах: `plan/ORIENT.md`, `plan/INDEX.md`, `.claude/commands/interview.md`,
`.claude/agents/adw-warden.md`, `.claude/agents/adw-builder.md`. Больше ничего.

## Границы

- `plan/PLATFORM.md` — **не трогать**: датированные разделы задним числом не правятся.
- `plugins/**` — не трогать вовсе; версия не двигается, потому что шипящееся не задето.
- `plan/findings/legacy.md` — не трогать: его удаляет закрывающий коммит волны, не эта задача.
- Ни одно правило не меняет смысла — меняется только адрес, по которому лежат тела F-серии.
- Никакого механизма. Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи **записанными строками**; ответ «до» назван у
каждой.

```bash
rtk proxy grep -rc 'legacy.md' plan/ORIENT.md plan/INDEX.md .claude/commands/interview.md .claude/agents/adw-warden.md .claude/agents/adw-builder.md
# до: 2, 5, 3, 2, 1. После: 0, 0, 0, 0, 0 — ни одного указателя на файл, который удаляется
rtk proxy grep -c 'legacy.md' plan/PLATFORM.md
# до: 2. После: 2 — датированные разделы не тронуты
rtk proxy grep -c 'F-231' plan/INDEX.md ; rtk proxy grep -c 'F-281' plan/INDEX.md
# до: 1 и 2. После: ≥1 и ≥1 — номера находок в протоколе сохранены, потерян только адрес
rtk proxy grep -ci 'никогда не читается целиком\|never read whole\|pointwise\|точечно' .claude/commands/interview.md
# до: 2. После: ≥1 — правило точечного чтения сохранено
git diff --stat -- plan/ .claude/
# до: пусто. После: ровно пять файлов
git status --porcelain -- plugins/
# до: пусто. После: пусто — шипящееся не задето
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — ровно пять файлов; `plan/PLATFORM.md` и `plugins/**` не тронуты;
- ни одного указателя на `legacy.md` в живых инструкциях и цитатах протокола не осталось;
- ни одно правило не сменило смысл: номера находок на месте, точечное чтение и запрет переписывать
  прежние диспозиции сохранены;
- английский в `.claude/**`, русский в `plan/**`;
- механизма нет; версия `plugins/adw` не тронута, потому что шипящееся не задето.
