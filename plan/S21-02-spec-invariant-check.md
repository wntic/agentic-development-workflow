# S21-02 — `/adw:spec`: черновой критерий читается против инвариантов живой спеки

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/commands/spec.md`) — warden докладывает про версию; подъём готовит
`/ship` при публикации, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — седьмая чистка (волна S21), прогоны цикла», строка **F-268**.

**Что это за задача.** В одном изменении (003 второй пробы) два черновых критерия требовали сцены,
которую запрещает инвариант, положенный предыдущим изменением той же способности. Первый пойман
интервью до коммита (цена ноль), второй прошёл насквозь и стоил вопроса человеку посреди
`/adw:build` и коммита правки спеки в середине цикла. Проверка чернового критерия против живой
спеки сегодня несистемна; после baseline тот же промах стоит `CONTRACT-CHANGE`. Класс растёт с
компаундингом спеки.

Читать сначала:

- `plugins/adw/commands/spec.md` целиком — команда короткая; адресат — шаг, где черновые критерии
  становятся `criteria.md` (сейчас шаг 3, строка ~130), и то, что команда уже говорит про живую
  спеку способности;
- тело записи грепом: `rtk proxy grep -n '^## F-268 ' plan/findings/legacy.md`, затем ~20 строк;
- строку решения по F-268 в секции решений 2026-08-10 (седьмая чистка) в конце того же файла.

## Задача

1. Одно-два предложения в шаг, где критерии ложатся в `criteria.md`: каждый черновой критерий,
   называющий **больше одной сущности в одном состоянии** (две брони, охватывающая и крайние
   геометрии, пара пересекающихся записей), прочитывается против инвариантов живой спеки способности
   **до** записи в `criteria.md` — инвариант, положенный прошлым изменением, может запрещать сцену
   целиком; замерено: два таких критерия в одном изменении, второй дошёл до середины сборки и стоил
   правки спеки внутри цикла.
2. Замер называется словами (как build.md цитирует прогон 004); номер находки не обязателен —
   идиома файла решает.
3. Ничего больше: остальные шаги интервью не переформулируются.

Файл шипится — текст английский, в тоне файла.

## Deliverables

Правка в одном файле `plugins/adw/commands/spec.md`. Больше ничего.

## Границы

- Другие файлы `plugins/adw/**`, `plan/**` (кроме чтения), `.claude/**` — не трогать.
- `plugin.json` не трогать: версия двигается командой `/ship` при публикации.
- Никакого механизма: предложение — шаг интервью, не проверка и не скрипт.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -ci 'invariant' plugins/adw/commands/spec.md
# до: 0. После: ≥1 — проверка против инвариантов названа
rtk proxy grep -c 'criteria.md' plugins/adw/commands/spec.md
# до: 4. После: ≥4 — шаг дописан, не переписан (пересчитай при расхождении и скажи почему)
git diff --stat -- plugins/adw/commands/spec.md
# до: пусто. После: один файл
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `spec.md`, одно-два предложения в существующий шаг;
- текст английский, замер назван словами, словаря дев-записи нет;
- версия `plugins/adw` не тронута — и это верно: подъём готовит `/ship`;
- механизма нет.
