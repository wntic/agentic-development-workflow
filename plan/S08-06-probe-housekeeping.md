## Задача

Housekeeping на базовой ветке, вне цикла изменений: **ни одного байта наблюдаемого поведения.**
Поэтому критериев нет и дельта не открывается — это установлено решением по F-122 и повторяет форму
коммитов `eecc6d5`, `46369e5`, `5d61cd5`.

**1. F-122 — предикат истечения переезжает в домен.** Замерено:

```bash
cd ~/Projects/adw-probe && /usr/bin/grep -rn 'expires_at is not None and' src/
# три копии: resolve_short_link_handler.py, get_short_link_info_handler.py, delete_short_link_handler.py
```

Три копии `x.expires_at is not None and self._clock.now() >= x.expires_at` схлопываются в один метод
сущности — `ShortLink.has_expired(now)` (имя твоё, но смысл этот): чистый домен, часов не тянет,
принимает момент. Комментарий сущности, который **отказывается** от правила («the comparison against a
clock belongs to the read handlers»), после переезда становится ложным и снимается или переписывается.
Граница `>=` против `>` сохраняется дословно: момент истечения **сам** считается истёкшим, и это
закрыто двумя unit-тестами (`test_the_expiry_instant_itself_counts_as_expired`).

Учти четвёртое место: change 006 добавил обращение к истечению в follow-путь. Проверь грепом, сколько
мест на самом деле, **прежде чем** писать число куда-либо.

**2. F-127 — три многострочных блока комментариев в `src/`.** Замерено (та же команда, что в S08-03):
`src: 3` — `application/links/resolve_short_link_handler.py`,
`infrastructure/postgres/repositories/short_link_repository.py`,
`infrastructure/postgres/tables/short_links.py`. Каждый сжимается до одной короткой строки либо
снимается, если «почему» из кода видно. **Тесты не трогать: 104 баннера в тестах законны** по решению
человека, и их чистка прямо запрещена.

**3. F-121 + F-120 — `line-length = 120` и ключи контракта на порту.** Порядок обязателен, потому что
это два разных предмета:

- **своим коммитом**: `line-length = 120` в `pyproject.toml` плюс `uv run ruff format`. Замерено, что
  реформат затронет **20 файлов из 67** (`uv run ruff format --check --line-length 120 src tests migrations`).
  Отдельный коммит нужен затем, чтобы реформат не прятал доменную правку;
- после него — ключи контракта возвращаются на порт одной строкой: `ConflictError` из `add` несёт
  `context["constraint"]` и `context["pgcode"]`. Замерено, что такая строка занимает 93–117 символов,
  то есть законна против 120 и незаконна против 88.

## Deliverables

Три коммита в `main` пробы, в этом порядке:

1. `line-length = 120` + реформат (ничего, кроме конфига и форматирования);
2. предикат истечения в домене + три блока комментариев в `src/` + ключи контракта на порту;
3. — если понадобится — ничего; третьего коммита быть не должно.

`make check` зелёный после **каждого** коммита. Отчёт называет: число тестов, число файлов в реформате,
сколько мест обращалось к истечению (посчитанное грепом, а не взятое из этого файла).

## Границы

- **Только `~/Projects/adw-probe`.** Ни одного файла этого репозитория.
- **Наблюдаемое поведение не меняется.** Ни одного нового поведения, ни одной правки утверждения
  теста, ни одного нового теста. Если для переезда предиката понадобился бы новый тест — **останов и
  вопрос**: это признак того, что правка не housekeeping.
- **`tests/**` — только то, что вынуждает переезд предиката** (например, фейк или конструкция
  сущности). Баннеры комментариев в тестах **не трогать вовсе**.
- **Живую спеку `specs/short-links.md` не трогать.** Прецедент правки спеки вне `/adw:accept` уже есть
  (`5d61cd5`), но здесь его повторять незачем: инварианты не двигаются.
- **Никакой смены возврата `CreateShortLinkHandler`** — это смена контракта, идёт спекой, и решение
  по F-123 её как раз легализует в текущем виде.
- **Ни одного скрипта, хука или файла состояния** — ни здесь, ни там.
- Не чинить найденное по дороге: всё, что найдёшь и что не входит в Deliverables, — в отчёт.

## Проверка

```bash
cd ~/Projects/adw-probe
git log --oneline -3                                          # два новых коммита, в названном порядке
/usr/bin/grep -rn 'expires_at is not None and' src/ | /usr/bin/wc -l   # 0 — копий предиката больше нет
/usr/bin/grep -rn 'has_expired' src/ | /usr/bin/wc -l         # метод и его вызовы
for d in src tests; do printf '%s: ' "$d"; for f in $(/usr/bin/find $d -name '*.py'); do /usr/bin/awk '{l=$0;sub(/^[ \t]+/,"",l)} l~/^#/{r++;next} {if(r>1)n++;r=0} END{if(r>1)n++; print n+0}' "$f"; done | /usr/bin/awk '{s+=$1} END{print s}'; done
# src: 0   tests: 104 — блоки в src ушли, баннеры в тестах не тронуты
/usr/bin/grep -n 'pgcode\|constraint' src/adw_probe/domain/links/i_short_link_repository.py   # ключи вернулись
make check                                                    # зелёный, число тестов назвать в отчёте
```

**И главная проверка, форма из F-119** — что поведение не изменилось. Сравни потоки токенов каждого
изменённого файла `src/**` против его версии до правки, выбросив `COMMENT`; для файлов, где менялись
только комментарии и форматирование, потоки обязаны совпасть. Файлы, где предикат переехал, совпасть
**не могут** — назови их отдельно и объясни каждый.

- **реформат отделён** от доменной правки своим коммитом;
- **баннеры в тестах не тронуты** — это требование решения, а не пропуск;
- `make check` зелёный после каждого коммита.
