# S21-04 — `build.md` §7: вторая ветка у `VERDICT: FAIL`, чья причина не в имплементации

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/commands/build.md`) — warden докладывает про версию; подъём
готовит `/ship` при публикации, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — седьмая чистка (волна S21), прогоны цикла», строка **F-271**.

**Что это за задача.** §7 даёт после `VERDICT: FAIL` одну ветку: новый диспатч имплементатора,
тратящий единицу потолка. В замеренном прогоне `FAIL` случился по причине, которую имплементатор не
лечит (маркированные тесты скипались за отсутствием учётных данных среды); прогон правильно поехал
не по маршруту — правки спеки решением человека, среда руками человека, третий диспатч оценщика,
ноль потраченных диспатчей имплементатора, — но опоры в командном файле у этого маршрута не было.
Оркестратор, читающий букву, отправил бы имплементатора чинить окружение и сжёг бы половину потолка.

Читать сначала:

- `plugins/adw/commands/build.md`, §7 целиком (ветка `VERDICT: FAIL` — строка ~261) и три уже
  описанных там диспатча, которые «не потратили ничего», — образец формы для новой ветки;
- тело записи грепом: `rtk proxy grep -n '^## F-271 ' plan/findings/legacy.md`, затем ~18 строк;
- строку решения по F-271 в секции решений 2026-08-10 (седьмая чистка) в конце того же файла.

## Задача

1. Вторая ветка в §7 рядом с существующей: `VERDICT: FAIL`, чью причину **не устраняет правка
   `src/`** — среда, учётные данные, механизм теста, формулировка критерия, — идёт к человеку и
   потолка имплементатора **не тратит**, по образцу трёх уже описанных там диспатчей. Замер
   называется словами: в замеренном прогоне такой `FAIL` разрешился правками спеки и среды руками
   человека, без единого диспатча имплементатора.
2. Существующая ветка (новый диспатч шага 5) не переформулируется — новая встаёт рядом как второй
   случай.
3. Ничего больше.

Файл шипится — текст английский, в тоне файла.

## Deliverables

Правка в одном файле `plugins/adw/commands/build.md`. Больше ничего.
