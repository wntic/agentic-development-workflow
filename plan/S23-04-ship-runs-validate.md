# S23-04 — `claude plugin validate` входит в подготовку шипа

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`.claude/commands/ship.md` — project-scoped, не шипится; версия не двигается)
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — девятая чистка (волна S23), платформа и плагин», строка **F-263**, вторая половина.
**Зависит от S23-03**: пока семь фронтматтеров красные, шаг проверки заведомо красит каждый прогон.

**Что это за задача.** `claude plugin validate` — единственная проверка манифеста, которую даёт
платформа. Решение вводит её в шаги `/ship`, и это **чтение команды, а не механизм**: бюджет
enforcement остаётся нулём, ни скрипта, ни хука, ни строки в `pre-commit` не появляется. Вердикт
валидатора смотрит человек, как и всё остальное, что `/ship` кладёт ему на стол.

Читать сначала:

- `.claude/commands/ship.md` целиком — команда короткая; адресат — блок шагов, где собирается
  шипящийся дифф и готовится предложение;
- тело записи грепом: `rtk proxy grep -n '^## F-263 ' plan/findings/legacy.md`, затем ~28 строк;
- строку решения по F-263 в секции решений 2026-08-10 (девятая чистка) в конце того же файла;
- `plan/INDEX.md`, секция «Версия плагина — правило движения» — чтобы новый шаг встал в её логику, а
  не рядом с ней.

## Задача

1. Шаг в `/ship`: перед предложением подъёма прогнать `claude plugin validate plugins/<name>` и
   показать человеку результат. Красный валидатор — не запрет публиковать: это факт на стол, и
   решает человек, как решает всё в этой команде.
2. Назвать, почему шаг существует: валидатор — единственная проверка манифеста, которую даёт
   платформа, и её вывод про рантайм **строже фактического** (замерено: рантайм парсит мягче), так
   что красное у него значит «манифест не пройдёт строгий YAML», а не «сегодня сломано».
3. **Читать код возврата, а не напечатанное число.** Замерено builder'ом S23-03 на копии дерева до
   правки: валидатор печатает `✘ Found 1 error:` **на каждый файл**, а в хвосте — только
   `✘ Validation failed`; семь сломанных файлов человек, глядящий на хвост, прочитает как один.
   Годная форма — код возврата (`0` при `✔ Validation passed`, `1` при провале) либо счёт грепом по
   строкам ошибок. Шаг называет это прямо, иначе он вводит в заблуждение ровно там, где поставлен
   ради точности.
4. Ничего больше: шаги сбора диффа, классификация по таблице и правило «решает человек» не
   переформулируются.

Файл — команда, по решению 2026-08-09 строго английский; текст — по-английски, в тоне файла.

## Deliverables

Правка в одном файле `.claude/commands/ship.md`. Больше ничего.

## Границы

- `plugins/**`, `plan/**` (кроме чтения), другие файлы `.claude/**` — не трогать.
- **Никакого механизма**: ни хука, ни строки в `.pre-commit-config.yaml`, ни скрипта — шаг команды,
  который исполняет сессия и читает человек.
- Валидатор не становится гейтом: красное не запрещает публикацию, оно её сопровождает.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи **записанными строками**; ответ «до» назван у
каждой.

```bash
rtk proxy grep -c 'plugin validate' .claude/commands/ship.md
# до: 0. После: ≥1 — шаг стоит
rtk proxy grep -ci 'the human decides\|decided by the human\|human decides' .claude/commands/ship.md
# до: 2. После: ≥2 — правило «решает человек» не ослаблено
git diff --stat -- .claude/commands/ship.md
# до: пусто. После: один файл
git status --porcelain -- plugins/ .pre-commit-config.yaml
# до: пусто. После: пусто — ни шипящееся, ни pre-commit не тронуты
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```
