# S24-01 — два примера миграции сжимаются до одной строки комментария

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`conventions`, `infra-persistence`) — warden докладывает про версию; подъём
готовит `/ship`, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — десятая чистка (волна S24), проза разошлась с деревом», строка **F-198**.

**Что это за задача.** Правило про комментарии, расширенное на `migrations/`, велит останавливаться
на многострочном блоке внутри `upgrade()`. Два шипящихся скилла несут в примере миграции комментарий
ровно такой формы — на **две** строки внутри `op.create_table`. Содержимое законное (почему `name=`
это суффикс, а не полное имя), но автор миграции копирует пример буквально и учится форме, за которую
его тормозит соседний скилл.

Решение чинит **пример**, а не правило: правило верно, и оговорка под него была бы часовым при живой
причине. Развилка (б) тела — оговорка про блок внутри списка аргументов — отклонена человеком.

Читать сначала:

- оба места и их окружение: `rtk proxy grep -n -B4 -A6 "A check constraint's .name. is the SUFFIX"
  plugins/adw/skills/conventions/SKILL.md plugins/adw/skills/infra-persistence/SKILL.md`;
- правило про комментарии в `python-style` (`rtk proxy grep -n -i 'multi-line' plugins/adw/skills/python-style/SKILL.md`)
  — форма, к которой примеры приводятся, и её точная формулировка;
- тело записи грепом: `rtk proxy grep -n '^## F-198 ' plan/findings/legacy.md`, затем ~20 строк;
- строку решения по F-198 в секции решений 2026-08-10 (десятая чистка) в конце того же файла.

## Задача

1. Оба комментария сжать до **одной** строки, сохранив довод: почему `name=` — суффикс, а не полное
   имя. Что именно сократить — по месту; довод обязан остаться понятным без второй строки.
2. Ничего больше: сам код примеров (`op.create_table`, аргументы, имена) не трогать, правило в
   `python-style` не трогать, соседние примеры не трогать.

Файлы шипятся — текст английский, в тоне соседей.

## Deliverables

Правки в двух файлах: `plugins/adw/skills/conventions/SKILL.md`,
`plugins/adw/skills/infra-persistence/SKILL.md`. Больше ничего.

## Границы

- Остальные файлы `plugins/adw/**`, `plan/**` (кроме чтения), `.claude/**` — не трогать.
- `plugin.json` не трогать: версия двигается командой `/ship` при публикации.
- Правило про комментарии не переформулируется и оговорки не получает — это отклонённая развилка.
- Никакого механизма. Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи **записанными строками**; ответ «до» назван у
каждой.

```bash
rtk proxy grep -c "A check constraint's .name. is the SUFFIX" plugins/adw/skills/conventions/SKILL.md plugins/adw/skills/infra-persistence/SKILL.md
# до: по 1 в каждом. После: по 1 — довод на месте, не удалён
rtk proxy grep -A1 "A check constraint's .name. is the SUFFIX" plugins/adw/skills/conventions/SKILL.md | rtk proxy grep -c '^ *#'
rtk proxy grep -A1 "A check constraint's .name. is the SUFFIX" plugins/adw/skills/infra-persistence/SKILL.md | rtk proxy grep -c '^ *#'
# до: 2 и 2 — за строкой довода идёт вторая строка комментария.
# После: 1 и 1 — за ней идёт код, комментарий однострочный.
# Форма `grep -c -A1` для этого не годится: `-c` считает совпавшие строки, `-A1` на счёт не влияет
# и даёт 1 при обоих исходах. Обе формы прогнаны — записана та, что различает.
git diff --stat -- plugins/adw/skills/
# до: пусто. После: ровно два файла
git status --porcelain -- plugins/adw/.claude-plugin/ plugins/adw/skills/python-style/
# до: пусто. После: пусто — ни версия, ни правило не тронуты
claude plugin validate plugins/adw 2>&1 | tail -1
# до: ✔ Validation passed. После: то же — фронтматтер не задет
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — ровно два файла, и в каждом тронут только комментарий внутри примера миграции;
- довод «`name=` это суффикс» сохранён и читается без второй строки;
- код примеров байт-в-байт; `python-style` не тронут;
- валидатор по-прежнему зелёный; версия `plugins/adw` не тронута;
- механизма нет.
