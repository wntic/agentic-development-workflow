2026-08-01 — правка карт делегирована»**, плюс строка `РЕШЕНО` в записи **F-85**.

Читать сначала:

  она короткая и она контракт этой задачи, включая то, что делать **не** надо

## Задача

Врезка `ORIENT.md` §4 «Писать по памяти о файле, который не открыл» выросла с 18 строк до 61,
объясняя, почему она выросла. Файл читают за пять минут в начале сессии; шестьдесят строк в одном
пункте эту функцию ломают. Плюс обе карты предписывают читать реестр командой, которая под здешним
хуком отдаёт две трети записей с обрезанными заголовками (F-85).

## Deliverables

### 1. `plan/ORIENT.md`, пункт «Писать по памяти о файле, который не открыл» в §4

Срезать примерно **до 20 строк**. Сохранить ровно три вещи:

- **констатацию с замером** — что это самый частый провал здесь и что он не лечится намерением;
  два прохода, в которых он замерен, названы одной фразой каждый, **без перечисления F-номеров**;
- **таблицу пяти проверок** — она и есть содержание пункта. Столбцы и строки не менять;
- **одну фразу о том, кто эти промахи ловил** (исполнитель, не автор задачи) и чем это обходится.

Убрать: абзац про то, почему перечни вместо счётчиков; два перечня F-номеров по происхождению;
пересказ трёх видов ошибки с числом. Всё это живёт в F-80, F-82, F-84 — вместо пересказа поставить
**одну ссылку** на них.

### 2. `plan/ORIENT.md` §5 и `CLAUDE.md`

Обе формы команды чтения реестра получают префикс `rtk proxy`:

- `ORIENT.md` §5: `grep '^## F-' …` и `grep -c '^## F-' …`;
- `CLAUDE.md`: «read by header (`grep '^## F-'`)».

Одной фразой в `ORIENT.md` — почему префикс нужен: голая форма переписывается хуком и возвращает
усечённый список молча. В `CLAUDE.md` объяснения не давать, там это деталь.

## Границы

- **Только два файла.** Ни `plan/FINDINGS.md`, ни канон, ни один файл под `plugins/adw/`.
- **Ни одного счётчика.** Решение человека от 2026-08-01 — «убрать счётчики, оставить перечни»;
  в срезанной версии не должно появиться ни числа записей реестра, ни числа находок, ни числа строк
  собственной таблицы. Если фраза требует числа — переформулируй фразу.
- **Не вводить правила из F-82 и F-84.** Их диспозиция за человеком; одна попытка ввести их без
  решения уже отклонена warden'ом. В таблице остаётся то, что там сейчас.
- **Не трогать три остальных пункта §4** («Предложить механизм», «Написать скрипт», «Починить
  найденное по дороге») и заголовок «Четыре способа сжечь день».
- **Не чинить `ORCHESTRATE.md` и `INDEX.md`**, где живёт неисполнимая форма `find`: F-71 называет их
  как ждущие решения человека.
- Не чинить найденное по дороге — находка в отчёт.

## Проверка

```bash
git status --short          # ровно два файла: plan/ORIENT.md и CLAUDE.md
rtk proxy grep -n "^## 4\.\|^## 5\." plan/ORIENT.md    # §4 должна кончаться заметно раньше
rtk proxy grep -n "grep '\^## F-'" plan/ORIENT.md CLAUDE.md   # обе формы с префиксом rtk proxy
rtk proxy grep -nE "[0-9]+ запис|[0-9]+ наход|[0-9]+ КБ|пятью проверк" plan/ORIENT.md   # счётчиков нет
```

Плюс чтением: пункт умещается на экран; таблица пяти проверок цела; три остальных пункта §4 не тронуты.
