# S11-03 — `/interview`: интервью по открытым находкам, решения в реестр до задач

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`.claude/commands/interview.md` — project-scoped, не шипится)
Происхождение: решение человека 2026-08-09, `plan/FINDINGS.md`, секция «Решения человека, 2026-08-09 —
петля разбора и интервью», строка «Интервью по находкам кодифицируется: `/interview`». Каталог
`.claude/commands` к моменту этой задачи перестроен S11-02.

**Что это за задача и чего она не делает.** Стоячий промпт человека — «находка → варианты с ценой →
рекомендация → мой выбор → исполнение по протоколу» — вводится по памяти каждый раз; класс молчаливого
расхождения копий измерен (F-132, F-71). Задача пишет **один файл** — команду `/interview` для главной
сессии этого репозитория. Команда ведёт интервью и записывает решения; **выбирает всегда человек** —
команда не решает за него ни одной развилки, и это её главная граница.

Читать сначала:

- шапка `plan/FINDINGS.md` — форма строки диспозиции (`- **F-N → …`, с нулевой колонки, по строке на
  запись) и правило «числа без команды не пишутся»: команда обязана вести себя по этой шапке;
- `plan/ORIENT.md` §5 — **дом** команды счёта открытых записей; в `/interview` она не копируется;
- `plan/INDEX.md`, секция «Протокол цепочки» — то, на что команда передаёт исполнение решений; не
  пересказывать;
- `CLAUDE.md`, абзац о двух привычках («a finding's disposition is the human's call…» и «the outcome
  to prefer is a finding that closes without a guard of its own») — предпочтение, которое интервью
  называет вслух при каждой рекомендации;
- `.claude/commands/debrief.md` (после S11-02) — сосед по петле: голос и формат фронтматтера.

## Задача

Один файл: `.claude/commands/interview.md`, по-русски. Фронтматтер: `description` (интервью по
открытым находкам: предъявление, варианты с ценой, рекомендация; решения — в реестр до файлов задач)
и `argument-hint` (`[F-NNN F-MMM … | пусто — все открытые]`). Тело — шаги главной сессии:

1. **Множество записей**: из аргументов; без аргументов — команда счёта открытых из `plan/ORIENT.md`
   §5, **скопированная оттуда при прогоне** — стоячей копии в этом файле нет (F-132: копия в стоячем
   файле расходится молча). Партию на один заход задаёт человек.
2. **По одной записи**: прочитать её тело (заголовочный греп, затем только это тело — реестр целиком
   не читается); предъявить суть в двух-трёх предложениях, класс и «что сломается»; **2–4 варианта
   решения, у каждого цена**; рекомендация с доводом. Канонное предпочтение называется вслух: лучший
   исход — закрытие **без правки и без гарда** (снятие причины лучше сторожа; «не наступило» — законная
   развилка, если названа с сигналом переоткрытия); механизм — только под `ИЗМЕРЕНО` и только решением
   человека. `AskUserQuestion` использовать можно, когда доступен; вариант человека вне списка — всегда
   законный ответ.
3. **Решения — в реестр до первого файла задачи** (F-113): датированная секция
   «Решения человека, <дата> — …» в конце `plan/FINDINGS.md`, по строке диспозиции на запись — форма
   строки задана шапкой реестра и здесь не пересказывается. Коммит решений — отдельный, до задач.
4. **Исполнение**: превращение решений в файлы задач и цепочка диспатчей — по секции «Протокол
   цепочки» `plan/INDEX.md`, не пересказывая её; счёт красной линии 3 называется до начала, командой,
   а не по памяти.
5. **Останов — нормальный исход**: запись, требующая замера, уходит в задачу prober'а решением
   человека, а не в догадку интервью.

И границы команды, в её же тексте: команда не выбирает за человека; тела читаются точечно; прежние
формы диспозиций в реестре задним числом не переписываются.

## Deliverables

Один файл `.claude/commands/interview.md`. Больше ничего.

## Границы

- Ни байта под `plugins/adw/`; `.claude/commands/debrief.md` и четыре симлинка не трогаются.
- `plan/ORIENT.md`, `plan/INDEX.md`, `plan/FINDINGS.md` не правятся.
- Команда счёта открытых в файл не копируется — только указание на её дом (`ORIENT` §5).
- Не чинить найденное по дороге: находка идёт в отчёт, пишет её главная сессия.

## Что скажет warden

- один файл, project-scoped; шипящееся и соседние файлы петли не тронуты;
- выбор всюду за человеком — в тексте команды нет ни одной ветки, где она решает сама;
- команда открытых, форма диспозиции и протокол цепочки процитированы домами, не скопированы;
- предпочтение «закрытие без гарда» названо словами канона, механизм — только под `ИЗМЕРЕНО`;
- живой прогон `slash_commands` показан с выводом.
