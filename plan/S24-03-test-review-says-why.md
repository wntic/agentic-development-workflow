# S24-03 — `test-review` объясняет, почему у него форма другая

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/agents/test-review.md`) — warden докладывает про версию; подъём
готовит `/ship`, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — десятая чистка (волна S24), проза разошлась с деревом», строка **F-221**.

**Что это за задача.** Формулировка «…if it were the first — and say whether any test would catch
it» была убрана из шаблона вердикта (шаблон приведён к форме «применить, прогнать, откатить») и
осталась третьим экземпляром в `test-review`. **И это, скорее всего, верно, а не дефект:** у красной
фазы реализации ещё нет, мутацию строить не из чего, и рассуждение — единственная доступная форма.

Дефект в том, что **причина расхождения нигде не названа**. Два файла дословно расходятся в одном
месте и совпадают в соседнем (перечисление слабых утверждений идентично), и самый дешёвый способ
«вернуть рассуждение в вердикт» — прочитать формулировку у `test-review` и перенести обратно, то есть
откатить F-214 через файл, с которого копируют.

Решение — развилка (а): одна строка объясняет, почему форма другая, и расхождение читается как
намеренное.

Читать сначала:

- `plugins/adw/agents/test-review.md` — место формулировки и её окружение:
  `rtk proxy grep -n -B8 -A4 'say whether' plugins/adw/agents/test-review.md`;
- `plugins/adw/templates/verdict.md`, раздел `## Adversarial pass` — форма «применить, прогнать,
  откатить», к которой шаблон приведён; **читать, не править**;
- тело записи грепом: `rtk proxy grep -n '^## F-221 ' plan/findings/legacy.md`, затем ~22 строки;
- строку решения по F-221 в секции решений 2026-08-10 (десятая чистка) в конце того же файла.

## Задача

1. Одна строка рядом с формулировкой: у этой роли **красная фаза** — реализации ещё нет, мутацию
   построить не из чего, поэтому здесь рассуждение, а не построенная и откаченная мутация; там, где
   реализация есть, форма другая.
2. Саму формулировку не менять — она верна для своей фазы.
3. Ничего больше: шаблон вердикта не трогать, остальные части роли не переформулировать.

Файл шипится — текст английский, в тоне файла; на другую роль по имени ссылаться не обязательно —
достаточно сказать, что форма зависит от того, есть ли реализация.

## Deliverables

Правка в одном файле `plugins/adw/agents/test-review.md`. Больше ничего.

## Границы

- `plugins/adw/templates/verdict.md` и `plugins/adw/agents/evaluator.md` — **не трогать**, только
  читать.
- Остальные файлы `plugins/adw/**`, `plan/**` (кроме чтения), `.claude/**` — не трогать.
- `plugin.json` не трогать: версия двигается командой `/ship` при публикации.
- Никакого механизма. Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи **записанными строками**; ответ «до» назван у
каждой.

```bash
rtk proxy grep -c 'say whether' plugins/adw/agents/test-review.md
# до: 1. После: 1 — формулировка на месте, не переписана
rtk proxy grep -ci 'no implementation exists\|nothing to mutate' plugins/adw/agents/test-review.md
# до: 0. После: ≥1 — причина расхождения названа
git status --porcelain -- plugins/adw/templates/ plugins/adw/agents/evaluator.md
# до: пусто. После: пусто — шаблон и соседняя роль не тронуты
git diff --stat -- plugins/adw/
# до: пусто. После: ровно один файл
claude plugin validate plugins/adw 2>&1 | tail -1
# до: ✔ Validation passed. После: то же
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `test-review.md`, добавлено объяснение; формулировка не изменена;
- шаблон вердикта и `evaluator.md` не тронуты;
- объяснение говорит о фазе (реализации нет — мутацию не построить), а не о том, кто эту роль
  вызывает;
- валидатор зелёный; версия `plugins/adw` не тронута;
- механизма нет.
