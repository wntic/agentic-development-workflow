# S01 — пять монолитов, за которые платит каждый диспатч

Тип: правка каталога. Слой: **ядро** (тела скиллов).
Отображение имён и форма указателя — **`plan/S00-skill-reference-map.md`**, выводить заново нельзя.

Читать сначала:
- `plan/S00-skill-reference-map.md` целиком — отображение и четыре формы указателя
- `plugins/adw/skills/meta-skill-author/SKILL.md`, правило 5 (cross-cutting ссылаются, не
  пересказываются) и правило 8 (никаких авторских заметок в теле)
- сами пять файлов, каждый перед его правкой — целиком, а не грепом
- `plan/FINDINGS.md`, F-45 (остатки «гейта») и F-48 (почему список слов — не признак протечки)

## Почему эти пять первыми

`implementer` предзагружает девять тем = **1 711 строк**, из которых **1 605 (94%) — эти пять
файлов**. Замеренная цена предзагрузки ≈41,7 тыс. токенов платится на каждом диспатче, и она
практически целиком здесь. Всё, что в этих файлах висит, висит в контексте каждой роли, которая их
несёт.

В каждом файле сделать **три** вещи и только их:

1. **Фантомные ссылки → адреса по S00**, каждая в форме своего случая. Формы разные, и это решается
   чтением строки, а не заменой подстроки:
   - маршрутный пункт «Package mechanics inside a layer → `general-python-package`»
     (`architecture:22`) указывает на **содержимое этого же файла** → становится ссылкой на свой
     раздел (`→ §<Заголовок> ниже`);
   - «package wiring (defer to `general-python-package`)» (`domain-model:15`) → квалифицированная
     ссылка на монолит: ``→ `architecture` §<Заголовок>``;
   - мягкая ссылка «see `general-logging`» → та же квалифицированная форма, `python-style`.
2. **Удалить маркеры `<!-- merged from … -->`.** Их запрещает правило 8 самого каталога: это заметка
   автору, а не агенту, и она едет в контекст. Тринадцать штук в этих пяти файлах.
3. **Остатки третьего захода — по одному сайту, названному явно:**
   - `architecture/SKILL.md:177` — «An unsorted literal is a **gate** finding» → назвать инструмент,
     который это ловит на самом деле (`RUF022`);
   - `conventions/SKILL.md:177` — «the **gate's** Docker tier» → «интеграционный ярус»;
   - `conventions/SKILL.md:236` — «wakes **the implementer** to author the next revision» → пассив без
     роли: ревизия пишется, когда появился дрейф схемы;
   - `conventions/SKILL.md:221` — «the lone, disciplined exception **(B8)**»: этот файл нумерует свои
     разделы буквами A–E, значит `B8` — идентификатор откуда-то ещё. **Проверить происхождение**; если
     это ссылка на регистр третьего захода — снять, если внутренняя нумерация этого файла — оставить и
     сказать это в отчёте.

## Границы

- **Ни одно правило по существу не меняется.** Это переадресация ссылок и снятие мусора, а не ревизия
  house style. Изменился адрес — не содержание.
- **Текст между темами не переносится.** Указатель ведёт в тему, где нужного раздела нет → это
  находка, не повод перенести абзац.
- **Фронтматтер не трогается** ни в одном из пяти файлов: ни `description`, ни `when_to_use`, ни
  `name`. Бюджет 1536 замерен и соблюдён у всех тринадцати тем, менять его нечего.
- Шаблоны кода, примеры, `Hard stops` по существу — не трогать.
- Не чинить соседей: `testing-unit` (это S04), топик-файлы (это S02), `CONVENTIONS.md` и
  `meta-skill-author` (это S03), `restapi`/`infra-*` (S02).
- Ловушка F-48: **не заменять по списку слов.** `restapi/auth-dependency.md:7` («routes an authed app
  gates») — законный глагол; «baseline revision» в `conventions` — терминология Alembic. Оба не
  трогать. В этих пяти файлах каждое попадание читается глазами.
- Ни скрипта, ни `sed` по всему дереву, ни файла состояния.

## Проверка

- Изменены ровно пять файлов.
- `grep -rE '`(general|domain|infra|test|testing|restapi|application|pattern)-[a-z-]+`'` по этим пяти
  файлам → **ноль**, кроме имён существующих тем (`architecture`, `python-style`, `conventions`,
  `domain-model`, `domain-ports`, `application`, `infra-persistence`, `infra-integration`, `restapi`,
  `testing-unit`, `testing-integration`, `meta-skill-author`, `meta-uc-author`).
- `grep -r '<!-- merged from' ` по этим пяти → **ноль**.
- `grep -inE '\bgates?\b' ` по этим пяти → либо ноль, либо только законный глагол, названный в отчёте.
- `grep -nE '\b(implementer|test-author|test-review|evaluator|coordinator)\b'` по этим пяти → **ноль**.
- Фронтматтер побайтово не изменён: `git diff` не показывает строк между первым и вторым `---`.
- Число строк каждого файла изменилось только за счёт снятых маркеров (±несколько), а не за счёт
  переписанных абзацев.
- Ни одного `.py`, `.sh`, `hooks.json`, `anchors.json` нигде.
