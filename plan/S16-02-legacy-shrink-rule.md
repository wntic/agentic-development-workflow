# S16-02 — строка о худеющем legacy в `ORIENT` §5

Тип агента: **`adw-builder`**
Слой: **дев-запись**
Происхождение: решение человека 2026-08-09, `plan/INDEX.md`, секция «`/ship` и худеющий legacy — S16»,
буллет «Legacy худеет поволново».

**Что это за задача.** Правило удаления в `ORIENT` §5 сформулировано для файла целиком («файл
удаляется закрывающим коммитом волны, исполнившей все его решения»); для `legacy.md` с 74 записями
это означало бы, что исполненные тела копятся неделями. Решение человека: волна удаляет из
`legacy.md` свои исполненные записи закрывающим коммитом, файл худеет и умирает с последней. Задача
вносит **одно дополнение в один файл**.

Читать сначала:

- `plan/ORIENT.md` §5 — буллет «Диспозиции — датированной секцией…» с правилом удаления;
- буллет решения в `plan/INDEX.md`, названный выше.

## Задача

В буллет правила удаления `plan/ORIENT.md` §5 добавить предложение: для `legacy.md` волна,
исполнившая **часть** записей, удаляет их (и их строки диспозиций) своим закрывающим коммитом —
файл худеет поволново и умирает вместе с последней записью. Остальной текст буллета не менять.

## Deliverables

Правка одного буллета в `plan/ORIENT.md`. Больше ничего.

## Границы

- Ни одно другое правило §5 не трогается; `plan/INDEX.md`, `.claude/**`, `plugins/**` — не трогать.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -c 'худеет' plan/ORIENT.md
# до: 0. После: ≥1 — правило внесено
rtk proxy grep -c 'удаляется закрывающим коммитом' plan/ORIENT.md
# до: 1. После: ≥1 — базовое правило не удалено
git diff --stat -- plan/ORIENT.md
# до: пусто. После: один файл, малый дифф
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — одно дополнение в одном буллете; базовое правило удаления цело;
- формулировка совпадает с буллетом решения в INDEX, ничего сверх него.
