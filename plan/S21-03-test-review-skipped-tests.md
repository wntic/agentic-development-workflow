# S21-03 — `test-review`: вердикт называет каждый маркированный тест, который не исполнился

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/agents/test-review.md`) — warden докладывает про версию; подъём
готовит `/ship` при публикации, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — седьмая чистка (волна S21), прогоны цикла», строка **F-270**.

**Что это за задача.** В прогоне 001 стороннего проекта два критерия скипались за отсутствием
учётных данных (скип санкционирован спекой — «skip loudly»), прошли четыре круга ревью — и когда
среда появилась, упали **против любой** имплементации: механизм теста был неверен с рождения.
Гарантия красной фазы «падает по правильной причине» для скипающегося критерия не действует, и в
вердикте он выглядит как остальные. Цена: первые в истории заходов правки `tests/**` после baseline
и третий диспатч оценщика.

Читать сначала:

- `plugins/adw/agents/test-review.md` целиком — адресат: форма вердикта и то, что роль уже требует
  прогнать сьют самой;
- тело записи грепом: `rtk proxy grep -n '^## F-270 ' plan/findings/legacy.md`, затем ~24 строки;
- строку решения по F-270 в секции решений 2026-08-10 (седьмая чистка) в конце того же файла.

## Задача

1. Правило в роль: вердикт **отдельной строкой называет каждый маркированный тест, который в
   прогоне ревью не исполнился** — скип, xfail за отсутствием среды, коллекция без запуска — с
   причиной; для такого критерия красная фаза **не считается пройденной**: гарантия «падает по
   правильной причине» держится только на исполнении, и тест, который не исполнялся ни разу, мог не
   уметь падать вовсе. Замер называется словами: два скипающихся критерия прошли четыре круга ревью
   и упали против любой имплементации, когда среда появилась.
2. Куда именно в файле — по месту: рядом с формой вердикта или требованием прогона; идиома файла
   решает.
3. Ничего больше.

Файл шипится — текст английский, в тоне файла.

## Deliverables

Правка в одном файле `plugins/adw/agents/test-review.md`. Больше ничего.

## Границы

- Другие файлы `plugins/adw/**`, `plan/**` (кроме чтения), `.claude/**` — не трогать.
- `plugin.json` не трогать: версия двигается командой `/ship` при публикации.
- Read-only-природа роли и остальная форма вердикта не переформулируются.
- Никакого механизма: правило — обязанность вердикта, не скрипт и не хук.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -ci 'did not execute\|never executed\|not executed' plugins/adw/agents/test-review.md
# до: 0. После: ≥1 — обязанность назвать неисполнившееся стоит
rtk proxy grep -ci 'skip' plugins/adw/agents/test-review.md
# до: 0. После: ≥1 — скип назван как форма неисполнения
git diff --stat -- plugins/adw/agents/test-review.md
# до: пусто. После: один файл
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `test-review.md`, одно правило дописано; форма вердикта расширена, не переписана;
- текст английский, замер назван словами;
- версия `plugins/adw` не тронута — верно, подъём готовит `/ship`;
- механизма нет.
