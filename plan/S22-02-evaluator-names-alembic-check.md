# S22-02 — `evaluator` называет `alembic check` среди проверок зелёной фазы

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/agents/evaluator.md`) — warden докладывает про версию; подъём
готовит `/ship` при публикации, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — восьмая чистка (волна S22), шаблоны инвариантов», строка **F-260**.

**Что это за задача.** `infra-persistence` требует: изменение, тронувшее и `Table`, и ревизию,
гоняет `uv run alembic check` **само**, руками — потому что дрейф между ними не ловит ничто другое.
Цена невыполнения замерена: расхождение `'[)'` против `'[]'` между `Table` и миграцией дало на сьюте
из 73 тестов **73 passed**. Это единственная в дереве обязательная проверка, у которой нет места,
где её исполнение наблюдаемо: ни `make check`, ни роль, ни шаг команды цикла её не держат, и всё
зависит от того, вспомнит ли реализатор.

Решение человека — развилка (в) тела: отдать роли. Бюджет enforcement остаётся **нулём** — ни
скрипта, ни пятой команды `make`; меняется только то, что оценщик обязан сказать в вердикте, гонял
ли он её и что она ответила. Развилка (б) — внести в `make check` — отклонена человеком прямо:
она делает бюджет ненулевым.

Читать сначала:

- `plugins/adw/agents/evaluator.md` целиком — как роль сегодня описывает зелёную фазу и что уже
  обязана предъявлять в вердикте (`make check` там named четырежды);
- `plugins/adw/skills/infra-persistence/SKILL.md`, строка с `alembic check` (`rtk proxy grep -n
  'alembic check' <файл>`) — формулировка правила и замер под ним;
- тело записи грепом: `rtk proxy grep -n '^## F-260 ' plan/findings/legacy.md`, затем ~17 строк;
- строку решения по F-260 в секции решений 2026-08-10 (восьмая чистка) в конце того же файла.

## Задача

1. Внести в перечень проверок зелёной фазы: **если дифф изменения тронул и `Table`, и ревизию
   Alembic — оценщик гоняет `uv run alembic check` сам и называет его вывод в вердикте.** Условность
   важна: изменение, не трогавшее миграции, её не гоняет и в вердикте о ней не пишет.
2. Назвать замер словами, по идиоме файла: дрейф между `Table` и миграцией не виден ни линтеру, ни
   типам, ни сьюту — замерено на сьюте из 73 тестов, где расхождение границ диапазона дало 73 passed.
3. Ничего больше: `make check` как определение зелёного не переформулируется, мутационный проход и
   форма вердикта не трогаются шире добавленной строки.

Файл шипится — текст английский, в тоне файла; номеров находок в нём нет и не появляется.

## Deliverables

Правка в одном файле `plugins/adw/agents/evaluator.md`. Больше ничего.

## Границы

- Другие файлы `plugins/adw/**` (включая `infra-persistence/SKILL.md` — правило в нём остаётся как
  есть, оно верно), `plan/**` (кроме чтения), `.claude/**` — не трогать.
- `plugin.json` не трогать: версия двигается командой `/ship` при публикации.
- **Никакого механизма**: ни строки в `Makefile`, ни скрипта, ни пятой команды — бюджет enforcement
  остаётся нулём, и это условие решения, а не пожелание.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

каждой.

```bash
# до: 0. После: ≥1 — проверка названа в роли

# до: 4. После: 4 — определение зелёного не тронуто
git diff --stat -- plugins/adw/agents/evaluator.md
# до: пусто. После: один файл — вклад задачи только здесь
git status --porcelain -- plugins/adw/skills/ Makefile
# до: пусто. После: пусто — ни скилл, ни Makefile не тронуты
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `evaluator.md`, добавлена условная проверка; `make check` как определение
  зелёного не сменил смысл;
- проверка **условна** — гоняется, только когда дифф тронул и `Table`, и ревизию;
- замер назван словами (73 passed при дрейфе), без номера находки;
- бюджет enforcement остался нулём: в диффе нет ни `Makefile`, ни скрипта, ни новой команды;
- версия `plugins/adw` не тронута — верно, подъём готовит `/ship`.
