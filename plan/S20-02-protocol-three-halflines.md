# S20-02 — три полустроки в протокол цепочки: пути коммита, доворот, «до» второго круга

Тип агента: **`adw-builder`**
Слой: **дев-запись**
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — шестая чистка (волна S20), дефекты файлов задач и дыры протокола», строки **F-230**,
**F-231**, **F-233**.

**Что это за задача.** Три замеренных промаха главной сессии, у которых в протоколе
(`plan/INDEX.md`, «Протокол цепочки») нет своей строки. F-230: `git add plan/` закоммитил чужую
незаревьюенную и одну отклонённую работу — ложный зелёный, зеркало F-99. F-231: доворот повторного
диспатча сослался на диспозицию, которой в реестре нет, и этот канал не оставляет следа. F-233:
«до»-состояние «Проверки» на втором круге описывает дерево, которого больше нет после коммита
первого круга.

Читать сначала:

- `plan/INDEX.md`, «Протокол цепочки» целиком — адресаты: шаг 4 (ветвление; там же уже стоят правила
  «не коммитить при чужом дифе» (F-281) и «повторный диспатч с вердиктом warden'а») и его абзацы;
- тела записей грепом по заголовкам, **не читая `legacy.md` целиком** (`ORIENT.md` §5):
  `rtk proxy grep -n '^## F-230 \|^## F-231 \|^## F-233 ' plan/findings/legacy.md`, затем ~28 строк
  каждое;
- строки решений по всем трём в секции решений 2026-08-10 в конце того же файла.

## Задача

1. Шаг 4, к правилу коммита: **коммит ставит свои пути** — `git add <пути задачи>`; `git add
   <каталог>` и `git add -A` в волне запрещены, симметрично правилу шага 1 о том, что проверка
   предъявляет свой дифф по своим путям (F-230; зеркало F-99: там ложный красный, здесь ложный
   зелёный).
2. Шаг 4, к ветке «Warden `ОТКЛОНИТЬ`»: **доворот повторного диспатча ограничен вердиктом warden'а
   и ссылкой на строку реестра**; всё остальное пишется в файл задачи, где остаётся следом (F-231:
   доворот — канал без следа, и правило «задача самодостаточна» существует именно против него).
3. Там же: **при повторном диспатче «до»-состояние «Проверки» переопределяется явно** — состояние на
   момент отклонения, а не нетронутое дерево (F-233: числа «после» сошлись бы и у исполнителя,
   принявшего чужой коммит за свою работу).
4. Ничего больше: существующие правила шагов 1–5 не переформулируются; три вставки — дописывание,
   не замена.

## Deliverables

Правка в одном файле `plan/INDEX.md`. Больше ничего.

## Границы

- `CLAUDE.md`, `plan/ORIENT.md`, `plan/findings/**`, `plugins/**`, `.claude/**` — не трогать.
- Секции «Активная волна», «Версия плагина», «Указатели» и таблица типов агентов — не трогать.
- Никакого механизма: три полустроки — правила протокола, не проверки и не хуки.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -c 'F-230\|F-231\|F-233' plan/INDEX.md
# до: 0. После: 3 — все три урока несут свои номера
rtk proxy grep -c 'git add' plan/INDEX.md
# до: 0. После: ≥1 — правило путей коммита стоит
rtk proxy grep -c 'момент отклонения' plan/INDEX.md
# до: 0. После: ≥1 — переопределение «до» стоит
rtk proxy grep -c 'F-281' plan/INDEX.md
# до: 1. После: 1 — соседнее правило коммита не тронуто
rtk proxy grep -c 'повторный диспатч builder' plan/INDEX.md
# до: 1. После: 1 — ветка ОТКЛОНИТЬ дописана, не переписана
git diff --stat -- plan/INDEX.md
# до: пусто. После: один файл — вклад задачи только здесь
rtk proxy find plugins/adw -name '*.py' -o -name '*.sh' -o -name 'hooks.json' -o -name 'anchors.json'
# до: пусто. После: пусто — красная линия 2
```

## Что скажет warden

- дифф — один файл `plan/INDEX.md`, тронут только протокол цепочки, три вставки;
- каждая вставка цитирует свой номер (F-230, F-231, F-233) как данные, без пересказа тел;
- существующие правила шагов (F-99, F-113, F-132, F-281, три круга) сохранены дословно или
  эквивалентно;
- механизма нет: ни скрипта, ни хука, ни новой проверки.
