# S13-04 — роли и команды: адресация нового реестра

Тип агента: **`adw-builder`**
Слой: **дев-запись** (`.claude/agents/*`, `.claude/commands/*` — project-scoped, не шипится)
Происхождение: решение человека 2026-08-09, `plan/FINDINGS.md`, секция «Решения человека, 2026-08-09 —
реестр по источникам, снос HISTORY.md» — вся модель целиком.

**Что это за задача.** Четыре репо-роли и две локальные команды адресуют `plan/FINDINGS.md` как живой
файл: builder велит главной сессии писать туда находки, warden открывает там цитаты решений, analyst
называет его формат, `/debrief` пишет в его конец, `/interview` считает открытое его командой. После
миграции все шесть адресов врут. Задача правит **адресацию** в шести файлах — и не меняет ни одной
роли по существу.

Читать сначала:

- секция решений, названная выше, — целиком (модель: файл на источник, диспозиции в нём, удаление
  закрывающим коммитом, «открыто» = `ls plan/findings/`, формат в `ORIENT` §5, серия заморожена);
- `rtk proxy grep -n 'FINDINGS' .claude/agents/*.md .claude/commands/*.md` — полный список мест;
- `.claude/commands/debrief.md` и `interview.md` целиком — их шаги переформулируются точечно.

## Задача

По файлам; язык всех шести — английский (решение 2026-08-09 о языке), русские токены-данные остаются.

**1. `.claude/agents/adw-builder.md`** — «The main session records it in `plan/FINDINGS.md`» и
родственные → «in the finding file of its source under `plan/findings/`»; блок «When the task
implements a decided finding»: rulings живут «in a dated decisions section **of the source's finding
file** (or, for the frozen F-series, `plan/findings/legacy.md`)». Смысл правил не трогать.

**2. `.claude/agents/adw-warden.md`** — пункт 2a (чтение цитат): адрес тот же новый; «Do not write to
`FINDINGS.md`» → «Do not write to the findings files»; упоминание в «The valve» — тем же образом.

**3. `.claude/agents/adw-analyst.md`** — «each in the house format of the `plan/FINDINGS.md` header»
→ формат по `plan/ORIENT.md` §5 (дом формата после S13-02); правило «You do not read
`plan/FINDINGS.md`» → «the findings files»; скелет `НАХОДКА` не меняется.

**4. `.claude/commands/debrief.md`** — шаг записи: прошедшие черновики пишутся главной сессией в
**файл источника** `plan/findings/<consumer>-<NNN>.md` (создать, если нет; формат — `ORIENT` §5;
поле `Найдено:` как раньше); граница «правок вне `plan/FINDINGS.md` нет» → «вне файла источника».

**5. `.claude/commands/interview.md`** — шаг 1: множество = аргумент (файл источника или его записи)
либо `ls plan/findings/` — счётной команды больше нет; шаг 3: решения — датированной секцией **в
конец файла источника**, до первого файла задачи (F-113 остаётся цитатой); новый финальный шаг:
когда все записи файла решены и исполнены — **файл удаляется закрывающим коммитом волны**, история в
git; граница «прежние формы диспозиций задним числом не переписываются» сохраняется для legacy.

**6. `.claude/agents/adw-prober.md`** — греп покажет, есть ли там адрес реестра; есть — привести,
нет — не трогать.

## Deliverables

Правленые файлы из списка выше — и только те из них, где греп нашёл адресацию. Больше ничего.

## Границы

- Ни одна роль не меняется по существу: read-only остаётся read-only, «пишет главная сессия»
  остаётся, потолки и формы возврата не трогаются.
- `plan/*` не трогать вовсе — ORIENT правит S13-02, реестр мигрирует S13-01, INDEX — главная сессия.
- `plugins/` не трогать.
- Не чинить найденное по дороге: находка — в отчёт.

## Проверка

Прогнана на нетронутом дереве до отправки задачи; ответ «до» назван у каждой строки.

```bash
rtk proxy grep -c 'FINDINGS\.md' .claude/agents/*.md .claude/commands/*.md | rtk proxy grep -v ':0'
# до: adw-builder 3, adw-warden 3, adw-analyst 2, debrief 4, interview 3 (пересчитай при исполнении).
# После: живых адресов записи ноль; допустимы только legacy.md и git-история
rtk proxy grep -c 'plan/findings/' .claude/commands/debrief.md .claude/commands/interview.md
# до: 0 и 0. После: ≥1 в каждом
rtk proxy grep -c 'grep -vxFf\|Чего не читать' .claude/commands/interview.md
# до: ≥1 (указание на счётную команду ORIENT §5). После: счёт открытого — ls, отсылки к счётной
# команде нет
git status --porcelain -- plan/ plugins/
# до и после: без изменений от этой задачи
```

## Что скажет warden

- дифф — адресация, не пересмотр ролей: границы, потолки, формы возврата, «кто пишет» — без правок;
- `/interview` несёт правило удаления файла закрывающим коммитом — и по-прежнему ни одной ветки,
  где команда решает за человека;
- проза шести файлов английская, русские токены — только данные;
- `plan/` и `plugins/` не тронуты этой задачей.
