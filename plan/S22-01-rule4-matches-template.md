# S22-01 — предложение Rule 4 приводится к своему шаблону

Тип агента: **`adw-builder`**
Слой: **шипящееся** (`plugins/adw/skills/test-discovery-invariants/SKILL.md`) — warden докладывает
про версию; подъём готовит `/ship` при публикации, здесь версия не двигается.
Происхождение: решение человека 2026-08-10, `plan/findings/legacy.md`, секция «Решения человека,
2026-08-10 — восьмая чистка (волна S22), шаблоны инвариантов», строки **F-253** и **F-255**.

**Что это за задача.** Одно предложение Rule 4 несёт два расхождения со своим же шаблоном.

Первое (F-253, `ИЗМЕРЕНО`): Rule 4 говорит «this test catches FastAPI bugs and decorator mismatches
alike», описывая сравнение как **точное**, — а в шаблоне стоит `_FRAMEWORK_VALIDATION_CODE` двумя
вхождениями, то есть ровно одно изъятие: `422`, который FastAPI вставляет сам. Реализатор,
следующий Rules вместо копирования шаблона, воспроизведёт ложное красное F-247 целиком — тот самый
механизм, ради которого изъятие и появилось.

Второе (F-255, `ПРЕДСТАВИМО`): то же предложение велит «Take both sides from the same
`iter_route_contexts(app.routes)` walk», но пояснение за двоеточием описывает только декораторную
сторону; сторона документа приходит из `app.openapi()`, а обход даёт лишь **ключ** (эффективный
путь), по которому две стороны сходятся. Реализатор будет искать коды документа на `RouteContext`,
где их нет.

Читать сначала:

- `plugins/adw/skills/test-discovery-invariants/SKILL.md` — Rule 4 целиком (сейчас строка 352) и
  **оба места шаблона**, где стоит `_FRAMEWORK_VALIDATION_CODE`, и место, где вызывается
  `app.openapi()`: `rtk proxy grep -n '_FRAMEWORK_VALIDATION_CODE\|app.openapi()' <файл>`;
- тела записей грепом, **не читая `legacy.md` целиком** (`ORIENT.md` §5):
  `rtk proxy grep -n '^## F-253 \|^## F-255 ' plan/findings/legacy.md`, затем ~12 строк каждое;
- строки решений по обеим в секции решений 2026-08-10 (восьмая чистка) в конце того же файла.

## Задача

1. Назвать изъятие: сравнение точное **кроме** кода валидации, который фреймворк вставляет сам, —
   шаблон держит его в `_FRAMEWORK_VALIDATION_CODE`, и Rules должны сказать об этом, иначе читающий
   Rules получит ложное красное на роуте, чей декоратор `422` не объявляет.
2. Поправить описание обхода: из обхода берётся **ключ**, по которому сходятся две стороны;
   декораторная сторона — с контекста роута, сторона документа — из `app.openapi()`.
3. Ничего больше: сам шаблон не трогать (он верен — это его проза разошлась), Rules 1–3 и 5+ не
   переформулировать, нумерацию не менять.

**Заодно, к сведению исполнителя, а не к правке:** заголовок записи F-255 называет это предложение
«Rule 2» — ошибка атрибуции в самой записи, зафиксированная её диспозицией; предложение живёт в
Rule 4, а «as Rule 2» в нём значит «тем же способом, что Rule 2».

Файл шипится — текст английский, в тоне файла; номеров находок в нём нет и не появляется.

## Deliverables
