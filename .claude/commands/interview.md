# /interview — разбор открытых находок с человеком

Ты — главная сессия этого репозитория. Твоя работа здесь — предъявлять, взвешивать и записывать;
**выбирает всегда человек**. Ни на одной развилке команда не решает сама: рекомендация — это довод,
не действие. Стоячий промпт этого интервью раньше вводился по памяти каждый раз; класс молчаливого
расхождения копий измерен (F-132, F-71) — теперь его дом этот файл, и второй копии у него нет.

## Шаги

1. **Множество записей.** Из `$ARGUMENTS` — список номеров `F-NNN`. Без аргументов — все открытые:
   их даёт команда счёта из `plan/ORIENT.md` §5 «Чего не читать», **скопированная оттуда при
   прогоне**. Стоячей копии этой команды здесь нет намеренно — копия в стоячем файле расходится
   молча (F-132). Полученный список покажи человеку и спроси, какую партию берём на этот заход;
   размер партии задаёт он.

2. **По одной записи, точечно.** Найди заголовок грепом по `^## F-NNN`, прочитай **только это
   тело** — реестр целиком не читается (`ORIENT` §5). Предъяви человеку:
   - суть в двух-трёх предложениях, класс (`ИЗМЕРЕНО` / `ПРЕДСТАВИМО`) и «что сломается»;
   - **2–4 варианта решения, у каждого — цена**: правка и её объём, «не наступило» с сигналом
     переоткрытия, замер, механизм;
   - рекомендацию с доводом.

   Канонное предпочтение называй вслух при каждой рекомендации, словами канона (`CLAUDE.md`, две
   привычки): «the outcome to prefer is a finding that closes **without a guard of its own**» —
   снятие причины лучше сторожа. «Не наступило» — законная развилка, если названа вместе с
   сигналом, который её переоткроет. Механизм — только под `ИЗМЕРЕНО` и только решением человека;
   `ПРЕДСТАВИМО` права на механизм не даёт.

   Спрашивай через `AskUserQuestion`, когда он доступен; вариант человека вне предложенного
   списка — всегда законный ответ, и записывается он, а не ближайший из твоих.

3. **Решения — в реестр до первого файла задачи** (F-113: задача, ссылающаяся на решение, которого
   в реестре нет, оставляет исполнителю нечего открыть, кроме самой себя). Датированная секция
   «Решения человека, <дата> — <тема>» в конце `plan/FINDINGS.md`, по строке диспозиции на запись;
   форма строки и правило «числа без команды не пишутся» — в шапке реестра, здесь они не
   пересказываются. Коммит решений — **отдельный, до задач**.

4. **Исполнение.** Превращение решений в файлы задач и цепочка диспатчей — по секции «Протокол
   цепочки» `plan/INDEX.md`; она не пересказывается, она исполняется. Счёт красной линии 3 назови
   **до начала исполнения** — командой из той же секции, не по памяти.

5. **Останов — нормальный исход.** Запись, требующая замера, уходит в задачу prober'а решением
   человека, а не закрывается догадкой интервью. Партия может закончиться и без единой правки —
   пятнадцать записей одного прохода закрылись ровно так.

## Границы

- Команда не выбирает за человека — ни одной развилки, решённой без его ответа.
- Тела записей читаются точечно; `plan/FINDINGS.md` целиком не читается.
- Прежние формы диспозиций в реестре задним числом не переписываются — их закрытость держит
  водораздел.
- Команда счёта открытых сюда не копируется — её дом `plan/ORIENT.md` §5.
